# Урок 4.5. Спасательные фразы: банк из 30 формулировок

Пятый урок модуля 4. Практикум-склад. Этот урок будете перечитывать чаще других.

## Зачем нужен банк фраз

Импровизация невозможна, когда вы в первый раз придумываете фразу на сцене. Банк существует, чтобы дать мозгу выбор из готового — выбор занимает секунду, придумывание — десять.

**Правило: банк доводится до автоматизма.** Не «знаю, что такие фразы есть», а «произношу их не думая». Это требует 3 недель проговаривания.

## Как пользоваться банком

Не читайте список на сцене. Тренируйте так:

1. Произнесите все 30 фраз подряд, 2 раза.
2. Потом закройте список и воспроизведите по памяти.
3. Через неделю — снова.
4. Через две недели — снова.

Когда список перестанет быть нужным, удалите его, но помните структуру.

## Категория 1. Технические проблемы (5 фраз)

**1. Звук пропал:**
```
«Так, друзья, техника решила отдохнуть — / продолжим без неё,
только ближе к вам»
```

**2. Музыка не играет:**
```
«Телефоны на зарядку! / Кто готов дать нам музыку для танцев?»
```

**3. Помехи, свист:**
```
«Так, друзья, секунду — / я сейчас это уберу»
```
(Идеально: уйти с зала на 30 секунд, починить, вернуться.)

**4. Не слышно технику (помощник):**
```
«Друзья, я сейчас вернусь. / Продолжайте веселиться»
```
(Выйти, разобраться, вернуться.)

**5. Сломалось оборудование для конкурса:**
```
«Так, а мы сделаем это иначе — / вот так»
```

## Категория 2. Не явились / отмена (5 фраз)

**6. Не пришёл именинник:**
```
«[Имя] подойдёт с минуты на минуту — / начнём, когда он будет»
```

**7. Гость опоздал:**
```
«Друзья, [Имя] в пути — / дадим ему добраться»
```

**8. Отменили танец:**
```
«Так, небольшое изменение плана — / давайте сделаем вот что»
```

**9. Отменили номер:**
```
«У нас тут сюрприз — / номера, который мы готовили, не будет. /
 Зато будет кое-что другое»
```

**10. Отменили тост:**
```
«Слово — [Имя]. / [пауза 3 сек] / Спасибо, что вы с нами»
```

## Категория 3. Отказ гостя (5 фраз)

**11. «Я не буду говорить»:**
```
«Что ж, не будем настаивать. / Спасибо, что вы сегодня с нами»
```

**12. «Я стесняюсь»:**
```
«Понимаю. / Тогда — вместе. / Я и [Имя] — два слова от вас»
```

**13. «Я не умею»:**
```
«И не надо уметь. / Скажите три вещи: / как вы их нашли,
 что пожелать, одно слово от души»
```

**14. Отказался, но хочет сказать:**
```
«Идёмте на минутку сюда — / скажете, что хотите. / Только для нас»
```

**15. Гость пьян и не может говорить:**
```
«Спасибо, [Имя], мы вас слышим. / Садитесь, вы сегодня герой»
```

## Категория 4. Зал не слушает (5 фраз)

**16. Зал шумит:**
```
«Друзья, давайте на секунду замолчим — / я скажу одну вещь»
```

**17. Говорят в телефон:**
```
«Те, кто в телефоне — / поднимите глаза, / я вам что-то скажу»
```

**18. Не слышно в дальнем углу:**
```
«Так, в дальнем углу не слышно? / [Имя], скажите, что слышно?» /
(После ответа — усилить или приблизиться.)
```

**19. Зал переговаривается:**
```
«Я чувствую, что у вас там дискуссия. / Кто готов рассказать,
о чём?»
```

**20. Все устали от речи:**
```
«Друзья, я тут полчаса говорю. / Может, дадите мне передохнуть?»
```

## Категория 5. Паузы и «я не знаю, что сказать» (5 фраз)

**21. Мост-пауза:**
```
«Кстати...»
```

**22. Наблюдение:**
```
«Я вот смотрю на зал — / и думаю...»
```

**23. Вовлечение:**
```
«О, а вот тут у нас мнения расходятся — / кто за?»
```

**24. Обещание:**
```
«Через пять минут будет кое-что интересное — / оставайтесь»
```

**25. Перезагрузка:**
```
«Так, давайте на секунду пересоберёмся»
```

## Категория 6. Эмоциональные моменты (5 фраз)

**26. Когда плачут:**
```
«Так... / видите? / А я говорил — / сегодня у нас день, который
запомнится»
```

**27. Когда смеются:**
```
(пауза 1,5 сек, спокойно смотрите) → следующая фраза
```

**28. Когда все поднимают бокалы:**
```
«Поднимаем бокалы! / За [кого]!»
```

**29. Когда надо сказать «спасибо»:**
```
«Спасибо. / По-настоящему. / Вот это — да»
```

**30. Когда надо закрыть блок:**
```
«Вот на этом — спасибо. / Дальше будет ещё интереснее»
```

## Универсальная фраза-мост

Если помните только одну фразу из всего банка — пусть будет эта:

```
«Так, друзья, / прежде чем мы продолжим — / давайте на секунду
остановимся и посмотрим друг на друга»
```

Работает при любой неловкости. Даёт 3 секунды. Переключает внимание. Зал не понимает, что происходит, но видит, что что-то происходит.

## Практика урока

**Задание 1. Чтение банка (10 минут).** Произнесите все 30 фраз, 2 раза подряд. Засеките время.

**Задание 2. По памяти (15 минут).** Закройте список. Воспроизведите по памяти все 30. Запишите, сколько вспомнили.

**Задание 3. Категория по ситуации (20 минут).** Возьмите 10 реальных ситуаций из своей практики. Подберите фразу из банка на каждую.

**Задание 4. Свои фразы (20 минут).** Напишите 10 своих фраз в стиле банка. Особенно на категории, которых не было у вас.

**Задание 5. Прогон в условиях (20 минут).** Расскажите другу историю, вставляя фразы из банка в неподходящие моменты. Проверьте, звучат ли они естественно.

## Домашнее задание недели

1. **30 фраз × 2 раза в день, 5 дней.**

2. **10 своих фраз** в стиле банка.

3. **Банк на карточке** — переписать от руки, положить в папку с документами.

4. **Проверка через неделю** — воспроизвести по памяти.

5. **Использование на ближайшем мероприятии.** Работать с карточкой: при ситуации — найти фразу, при ситуации — переключиться на следующую.

## Критерии проверки

- [ ] Все 30 фраз произнесены, 2 раза в день, 5 дней
- [ ] По памяти воспроизведено минимум 20 из 30
- [ ] Написано 10 своих фраз
- [ ] Фразы переписаны на карточку от руки
- [ ] 10 реальных ситуаций сопоставлены с фразами из банка
- [ ] Банк использован на реальном мероприятии хотя бы раз

## Что запомнить

1. Банк нужен, чтобы выбор занимал секунду, а не десять.
2. 6 категорий: техника, отмены, отказы, шум зала, паузы, эмоции.
3. Довести до автоматизма за 3 недели, потом список не нужен.
4. Универсальная фраза-мост: «Давайте на секунду остановимся и посмотрим друг на друга».
5. Фразы — не скрипт. Это опоры. Произносите своими словами то, что подходит.
6. После шутки — пауза, не следующая фраза.

## Вопрос для самопроверки

**Во время конкурса отключили свет в зале. Что делать в первые 5 секунд?**
Ожидаемый ответ: 1) Не суетиться, не кричать «ой». 2) Озвучить ситуацию, спокойно: «Друзья, у нас тут маленькая авария со светом — / через минуту всё починим. / А пока — все встают в круг ко мне, / кое-что придумаем». 3) Переключить зал на активность, не требующую света: хоровод, словесная игра, объятия, разговор в темноте (свечи, телефоны). 4) Параллельно: помощник или организатор ищут причину. 5) Когда свет включат — не комментировать аварию, просто продолжить: «Так, вернулись! / Продолжаем». Главное: зал не должен видеть, что вечер сломался. Авария — это 30–60 секунд, а не инцидент вечера.
