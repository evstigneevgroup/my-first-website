# Урок 4.4. Конфликты на мероприятии: пьяный гость, опоздавший, отменённый танец

Четвёртый урок модуля 4. Самые острые ситуации. Здесь нет «правильного» решения, есть framework принятия решений.

## Принцип: три уровня решения любого конфликта

**Уровень 1. Сам решить.** Мелкие проблемы, где вы справляетесь сами: кто-то не услышал конкурс, кто-то встал не туда, музыка чуть опоздала.

**Уровень 2. Привлечь.** Проблемы, где нужен другой человек: техника, ребёнок плачет, кто-то потерялся, нужен тамад/распорядитель, нужен доступ к помещению.

**Уровень 3. Отдать.** Проблемы, где вы не имеете права решать: конфликт между гостями, отказ алкоголя, вопросы безопасности, вопросы здоровья.

**Главная ошибка новичка — решать всё на уровне 1.** Это перегружает, приводит к ошибкам и превращает вас в «человека, который лезет во всё».

## Ситуация 1. Пьяный гость

**Ситуация:** гость сильно пьян, шумит, мешает, громко комментирует, пытается говорить в микрофон, портит тосты.

**Что происходит в зале:** все видят. Все ждут, что вы сделаете. Это момент, когда один урок заменяет сотню замечаний в интернете.

**Чего НЕЛЬЗЯ делать:**

```
— Публично стыдить («вы уже втрезвились, сядьте, пожалуйста»)
— Уводить силой
— Игнорировать, если он громкий и мешает
— Вступать в дискуссию
— Пугать жалобой полиции
— Делать вид, что всё нормально, когда всё ненормально
```

**Что делать (пошагово):**

**Шаг 1. Первый контакт — личный, громкий, с улыбкой.**
```
«[Имя], ну что, наливаем ещё? / Пойдём, я покажу тебе кое-что»
```
Задача: забрать его из зала, где он слышен, в зону где он не слышен. Три шага от места.

**Шаг 2. Если продолжает шуметь — привлеките помощника.** Помощник, тамад, распорядитель, официант, кто-то из семьи. Лучше, чтобы вас не видели в этой ситуации вообще.

**Шаг 3. Если входит в примитивную фазу (любой гость, хоть монахиня).**

```
«[Имя], вот вам стакан воды. / Пойдёмте на улицу подышать. / Я пойду с вами»
```

Тон: спокойный, уважительный, без обвинений. Территория: улица, балкон, коридор — место без гостей. Время: 5–7 минут, пока отходит.

**Шаг 4. Кто-то из семьи забирает.** Это работа организатора, не ведущего.

**Шаг 5. Вернувшись в зал — не упоминайте.**

**Главное правило: вы не полиция и не нянька.** Ваша работа — чтобы вечер продолжался. Пьяный гость — задача организатора, охраны и семьи. Вы помогаете и передаёте.

**Как предупредить заранее:**

Перед началом вечера скажите организатору:

```
«У вас будет человек, который может перепить. / Я с ним поговорю сам,
 если будет совсем плохо — позовите официанта»
```

Это не «стукать». Это профессиональная подготовка. Сделайте это на любом мероприятии, где есть алкоголь.

## Ситуация 2. Ребёнок ходит и мешает

**Ситуация:** ребёнок 4–8 лет ходит по залу, натыкается на столы, кричит, тащит еду.

**Варианты:**

| Ситуация | Ваше действие |
|---|---|
| Ребёнок тихо играет рядом с родителями | Игнорировать. Нормально |
| Ребёнок шумит, но не мешает гостям | Игнорировать |
| Ребёнок бегает по танцполу | Включить в конкурс или дать роль |
| Ребёнок плачет, родители в обстановке | Помочь родителям, не отвлекая зал |
| Ребёнок кричит во время тоста | Дождаться паузы, шуточно обратиться к ребёнку |

**Лучший ход — дать ребёнку роль:**

```
«[Имя], иди сюда. / Ты сегодня у нас главный помощник. /
 Пойдёшь со мной?»
```

Ребёнок с ролью занят, вы свободны, родители спокойны. Обратный ход: родители спокойны, ребёнок занят.

**Если ребёнок расплакался во время тоста:** дождитесь паузы в тосте (например, паузу родителя), обратитесь:

```
«Так, все вы видите, / что наш [Имя] уже начал готовить / сюрприз
 для мамы. / Подождём, когда высохнут щёки — / и продолжим»
```

## Ситуация 3. Спор между гостями

**Ситуация:** двое гостей говорят одновременно, перебивают друг друга, начинается перепалка.

**Что делать:**

**Шаг 1. Не вмешивайтесь в саму перепалку.** Это не ваш конфликт.

**Шаг 2. Назовите ситуацию публично (мягко):**

```
«Так, я вижу, что мнения у нас разные. / А это хорошо — значит,
 вечер не всем скучный. / Давайте дадим обоим сказать по 10 секунд»
```

**Шаг 3. Организуйте очередь:**

```
«[Имя], вы первый. / [Имя], вы второй. / Договорились?»
```

**Шаг 4. Если эскалация — привлеките организатора.**

**Чего нельзя:** вставать между ними, повышать голос, шутить над ситуацией.

## Ситуация 4. Опоздавший гость

**Ситуация:** часть гостей ещё не пришла, а уже пора начинать.

**Что делать:**

**Вариант 1. Ждать до 10 минут.** Если опоздавший — ключевая фигура (жених, именинник), подождите.

**Вариант 2. Начать без него.** Лучше начать без 5 гостей, чем ждать 15 минут.

**Вариант 3. Начать, но сделать паузу:**

```
«Друзья, некоторые из вас ещё в дороге — / дадим им
 пару минут, чтобы добраться»
```

Это уважительно, но не бесконечно. 10 минут максимум.

**Если опоздал юбиляр (именинник):**

```
«Ну наконец-то! / Мы вас заждались! / Давайте дождёмся
 [Имя] — без него вечер не начинается»
```

**Если опоздал кто-то из гостей:** начать без него, на следующей паузе сказать:

```
«Так, [Имя] только что подошла. / С возвращением!»
```

## Ситуация 5. Отменили танец

**Ситуация:** молодожёны отменили первый танец. Или отменили съёмку. Или отменили музыканта.

**Что делать:**

**Ситуация А. Отменили танец, а объявлять его уже поздно.**

```
«Так, друзья, небольшое изменение плана — / молодые попросили
 изменить первый танец. / Тогда мы сделаем вот что: /
 давайте все соберёмся ближе — / это будет первый танец
 ВАШЕЙ свадьбы!»
```

Превращаете провал в вовлечение зала.

**Ситуация Б. Отменили танец, но вечер продолжается:**

```
«Друзья, у нас тут небольшая смена плана. / Молодые попросили
 обойтись без первого танца. / Ничего страшного — мы просто
 начнём танцевать все вместе. / Танцуем!»
```

**Ситуация В. Отменили конкурс или номер:**

```
«Так, у нас тут сюрприз. / Номер, который мы готовили,
 решили не проводить. / Зато у нас будет кое-что другое — / сейчас увидите»
```

И сразу переходите к следующему блоку, не давая залу времени на раздумья.

**Правило: изменения озвучиваются в порядке «проблема → решение», без извинений и без деталей.**

**Шаблон:**

```
«Так, друзья, [проблема в одну фразу]. / [Решение в одну фразу]. / Действуем!»
```

## Ситуация 6. Не пришли ключевые гости

**Ситуация:** не пришли родители жениха, или именинник, или кто-то очень важный.

**Варианты:**

**Если можно подожти 5 минут — ждёте:**

```
«[Имя], мы начнём, как только вы будете. / Вас ждут!»
```

**Если ждать нельзя:**

```
«Так, наш [Имя] задерживается — начнём без него,
 а когда подойдёт — обязательно дадим ему слово»
```

**Психологический приём — обернуть в плюс:**

```
«Наш [Имя] добирается — / зато мы точно увидим,
 как [Имя] заходит на вечер, / это дорогого стоит»
```

Внимание: не врите, но и не акцентируйте проблему.

## Ситуация 7. Техника сломалась в неподходящий момент

Разобрано в модуле 3 (уроки 3.4 и 3.5). Здесь только напоминание:

```
Приоритет: не техника, а зал.
Зал не должен видеть панику.
Переключите формат, а не оправдывайтесь.
```

## Ситуация 8. Гость недоволен вами

**Ситуация:** гость подходит и говорит «вам не следовало так говорить» или «вы меня назвали неправильно» или «мне это не понравилось».

**Что делать:**

**Шаг 1. Искренне извинитесь:**

```
«Простите, это была неудачная шутка. / Я не хотел вас задеть»
```

**Шаг 2. Не оправдывайтесь.** Не объясняйте, что «я не хотел». Признайте и исправьте.

**Шаг 3. Если ошибка реальная (перепутали имя, перепутали факт) — исправьте публично:**

```
«Кстати, я ошибся: / на самом деле [правильный факт]. /
 Давайте я поясню»
```

Это поднимает вас в глазах зала.

**Шаг 4. Если гость агрессивен — отступайте.** Это не ваша работа.

## Общий алгоритм: 10 секунд на конфликт

Любой конфликт на мероприятии решается по одной схеме за 10 секунд:

```
1. ПАУЗА (2 сек) — остановиться, не паниковать
2. НАЗВАТЬ (2 сек) — коротко, без драмы
3. РЕШИТЬ (4 сек) — сказать, что будет
4. ПЕРЕЙТИ (2 сек) — к действию или следующему блоку
```

**Зачем нужна пауза:** без неё вы реагируете автоматически, и реакция обычно хуже, чем могла бы быть.

**Чего нельзя в конфликте:** повышать голос, улыбаться (это читается как насмешка), оправдываться, объясняться дольше 10 секунд, вовлекать зал в разбор.

## Практика урока

**Задание 1. Семь ситуаций (30 минут).** Для каждой ситуации напишите пошаговый алгоритм: что вы делаете в первые 5 секунд, что в первую минуту, что дальше.

**Задание 2. Шаблоны объявлений изменений (15 минут).** Напишите 5 шаблонов по формуле «проблема → решение» для разных изменений.

**Задание 3. Симуляция (20 минут).** Попросите друга разыграть ситуацию с пьяным гостем или недовольным. Отработайте алгоритм 10 секунд.

**Задание 4. Три уровня (15 минут).** Возьмите 10 типичных ситуаций, распределите по уровням 1, 2, 3. Обоснуйте.

**Задание 5. Разбор своей реакции (10 минут).** Вспомните случай, когда вы отреагировали на ситуацию неправильно. Что сделали бы иначе?

## Домашнее задание недели

1. **Алгоритмы по 7 ситуациям** — написаны.

2. **5 шаблонов объявления изменений** — написаны и проговорены.

3. **Симуляция с другом** — минимум 2 раза, записать.

4. **Распределение по 3 уровням** — 10 ситуаций.

5. **Предупреждение организатора.** Напишите фразу, которой вы предупредите организатора про возможные проблемы с алкоголем. Проговорите.

6. **Прогон «алгоритм 10 секунд».** Тренировать приём 20 раз в день.

## Критерии проверки

- [ ] Написаны алгоритмы по 7 ситуациям, с временными метками
- [ ] 5 шаблонов объявления изменений написаны и проговорены
- [ ] Симуляция проведена 2 раза, записи есть
- [ ] 10 ситуаций распределены по 3 уровням решения
- [ ] Написана фраза предупреждения организатора
- [ ] Вы можете описать алгоритм «10 секунд на конфликт»
- [ ] Вы можете объяснить, почему нельзя публично стыдить пьяного гостя

## Что запомнить

1. Три уровня: решить самому, привлечь, отдать. Не решайте всё сами.
2. Пьяный гость: личный контакт → помощник → вывод из зала → семья забирает. Не вы.
3. Предупреждайте организатора про алкоголь заранее — это профессионализм, не «стукать».
4. Изменения: «проблема → решение», без извинений, без деталей.
5. Алгоритм конфликта: пауза → назвать → решить → перейти. 10 секунд.
6. Нельзя: повышать голос, улыбаться, оправдываться, вовлекать зал.

## Вопрос для самопроверки

**Вы ведёте свадьбу. В 21:00 пьяный отец невесты встаёт и говорит тост, но говорит 12 минут, зал шумит, в какой-то момент отключили его от микрофона в техническом помещении. Ваши действия?**
Ожидаемый ответ: 1) Пауза 2 секунды — не показывать панику. 2) Назвать ситуацию без обвинений: «Так, дорогие гости, / сейчас у нас будет пауза — / а пока мы послушаем музыку». 3) Отключить звук, включить музыку на 2–3 минуты — зал переключится. 4) В это время: переговорить с отцом невесты, спокойно, лично, в стороне: «[Имя], спасибо за тосты, мы вас любим. / Давайте продолжим программу — / ваш тост будет самым тёплым в конце вечера». 5) Если отец продолжит бунтовать — привлечь организатора и родственников. 6) Вернуться к программе с точки следующего блока, не делая вид, что был «перерыв». Ключевое: зал не должен видеть, что кто-то «сорвал программу». Он должен видеть паузу, а потом — следующий блок.
