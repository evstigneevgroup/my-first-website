# Чек-лист выпускника

Один файл, который отвечает на вопрос: «Я закончил курс или ещё нет?». Распечатайте или скопируйте в заметки и проходите по нему после каждого модуля.

**Как пользоваться:** проходите сверху вниз, честно отвечая «да» или «нет». Если набралось больше пяти «нет» — вернитесь в соответствующий модуль и доработайте. Если на одно «нет» не хватает двух недель практики — всё в порядке, отметьте дату и вернитесь.

**Дата начала курса:** _______________
**Дата первого мероприятия:** _______________

---

## Модуль 1. Голос и речь

- [ ] Держу 3 минуты с микрофона без паразитов и «э-э-э»
- [ ] Темп держу в диапазоне 110–130 слов в минуту осознанно
- [ ] Знаю свои 3 проблемных звука и упражнение на каждый
- [ ] Ставлю паузу 1,5 секунды после ключевых фраз
- [ ] Меняю интонацию каждые 2–4 минуты
- [ ] Могу остановить себя стоп-словом за 5 секунд
- [ ] Имею 5 отработанных фраз-мостов для выхода из срыва
- [ ] Записал голосовой отчёт 90 секунд, выбрал лучший дубль

## Модуль 2. Сценарий и тайминг

- [ ] Есть каркас вечера из 7 блоков
- [ ] Есть минутная сетка с резервом 10% и тремя контрольными точками
- [ ] Открытие написано в трёх вариантах, один выбран
- [ ] Есть подводки, представления, добивки, фразы-мосты
- [ ] Есть полный сценарий в формате «дословно / импровизация»
- [ ] Есть финал с мягким приземлением
- [ ] Есть 6 рабочих карточек, написанных от руки
- [ ] Ключевые факты (имена, даты, цифры) выучены наизусть
- [ ] Провёл прогон 40 минут без текста сценария

## Модуль 3. Техника и звук

- [ ] Собрал рабочий комплект: микрофон, колонка, кабели, удлинитель
- [ ] Есть запасной микрофон (или куплен и лежит в сумке)
- [ ] Подключаю комплект с нуля за 10 минут
- [ ] Проверил звук в чужом помещении, не в своей комнате
- [ ] Знаю, что делать за 60 секунд, если звук пропал
- [ ] Есть написанный сценарий вечера без микрофона
- [ ] 30% практики провёл без микрофона

## Модуль 4. Импровизация и зал

- [ ] Есть банк из 30 фраз-спасателей, все отработаны
- [ ] Умею удержать зал без шуток (паузы, вопросы, движение)
- [ ] Знаю 5 тактик работы с неохотными и применяю их по порядку
- [ ] Умею вывести неконфликтного человека на сцену
- [ ] Знаю три уровня решения конфликта: решить / привлечь / отдать
- [ ] Отработал сценарии: пьяный гость, опоздавший, ребёнок, спор, отмена
- [ ] Работаю с залом всем телом: хожу, смотрю, меняю точки
- [ ] Заполнил 15 минут импровизации без подготовки
- [ ] Провёл репетицию с публикой (друзья, родственники)

## Модуль 5. Форматы

- [ ] Есть полный сценарий свадьбы
- [ ] Есть полный сценарий корпоратива
- [ ] Есть полный сценарий юбилея / дня рождения
- [ ] Есть полный сценарий уличного (публичного) события
- [ ] Есть сценарий детского праздника
- [ ] Заполнены карточки профилей форматов
- [ ] Заполнена матрица конкурсов
- [ ] Умею пересобрать сценарий под другой формат за 40 минут
- [ ] Каждая шутка проверена на уместность в каждом формате

## Модуль 6. Профессия

- [ ] Понимаю, из чего складывается цена, и умею посчитать свою
- [ ] Есть коммерческое предложение с тремя пакетами
- [ ] Есть договор-шаблон со всеми обязательными пунктами
- [ ] Есть анкета клиента и заполненный бриф по одному заказу
- [ ] Есть таблица учёта заказов, заполненная по факту
- [ ] Запросил 5 отзывов, получил хотя бы 1
- [ ] Есть 3 состоявшиеся рекомендации или понимаю, как их получить
- [ ] Знаю 4–5 рабочих каналов поиска клиентов
- [ ] Умею отказать неподходящему заказу с аргументом
- [ ] Знаю свою цену и следующий шаг по её повышению
- [ ] Есть план роста на 12 месяцев с критериями проверки

## Практика

- [ ] Провёл хотя бы одно мероприятие (пусть бесплатное)
- [ ] Получил обратную связь от людей, которые были на мероприятии
- [ ] Разобрал свои ошибки после первого выступления
- [ ] Выбрал формат для второго мероприятия осознанно
- [ ] Записал, что именно улучшить во втором вечера

```
Рекомендаций состоялось:    ____
Формат для следующего:      ____________
Что улучшить в следующий раз: __________________________________
```

## Три вещи, без которых нельзя

Если из всего списка оставить только три пункта:

```
1. ЧЕСТНОСТЬ. Если вы не готовы сказать «не знаю, что делать» —
   вы начнёте импровизировать в микрофон. Это хуже.

2. ПОДГОТОВКА. Сценарий, тайминг, карточки. Не для вас —
   для зала. Зал не знает, что вы волнуетесь, но чувствует.

3. РЕПЕТИЦИЯ. Первый вечер вы проиграете. Второй — меньше.
   Десятый — будете вести, а не играть.
```

**Курс закончен, когда вы провели мероприятие.** Не когда прочитали последний урок.
