# Урок 5.6. Адаптация: как переиспользовать один сценарий под четыре формата

Шестой урок модуля 5. Закрывает модуль и экономит вам недели работы.

## Принцип: ядро общее, оболочка разная

80% работы по сценарию — общее: структура, открытие, тосты, конкурсы, финал. Различаются 20%: формат, тон, длина, техника.

**Вывод:** не нужно писать четыре сценария с нуля. Нужно написать один и научиться его пересобирать.

## Что общее у всех форматов

```
— Выход и пауза
— Открытие по формуле «обращение → идентификация → контекст → крючок»
— Представление гостей
— Подводки к блокам
— Тосты (своя структура, но та же логика)
— Конкурсы (свои, но та же механика)
— Финал с мягким приземлением
— Работа с залом
— Работа с форс-мажорами
```

## Таблица различий

| Параметр | Свадьба | Корпоратив | Юбилей | Уличное |
|---|---|---|---|---|
| Главные герои | Двое | Коллектив | Один | Толпа |
| Тон | Тёплый, праздничный | Деловой, уважительный | Личный, тёплый | Энергичный, громкий |
| Темп | Средний | Разгонный → торжественный | Медленный | Быстрый |
| Длина фраз | 10–15 слов | 10–20 слов | 8–12 слов | 5–7 слов |
| Юмор | Умеренный | Минимальный | Умеренный | Активный |
| Конкурсы | 2–3 сложных | 1–2 простых | 1–2 спикерских | 1–2 быстрых |
| Тосты | 3–5 | 1–2 (руководитель) | 3–5 | Нет |
| Техника | Микрофон, колонка | Микрофон, колонка, экран | Часто без техники | Часто без техники |
| Тайминг | Гибкий | Жёсткий | Гибкий | Очень жёсткий |
| Главный риск | Эмоции, опоздания | Регламент | Усталость героя | Погода, шум |

## Метод пересборки: 6 шагов

Взяв готовый сценарий одного формата, превратите его в другой за 30–40 минут.

**Шаг 1. Определите героя.**
Кто главный в новом формате? От этого зависит всё остальное.

```
Свадьба → пара (вы в фокусе — они)
Корпоратив → компания и люди
Юбилей → один человек
Улица → толпа
Детский → дети
```

**Шаг 2. Перепишите открытие.**
Тот же шаблон «обращение → идентификация → контекст → крючок», но другой тон и герой.

**Шаг 3. Пересоберите конкурсы.**

Вопросы для себя:

```
— Насколько сложный конкурс допустим? (дети < юбилят < гости свадьбы < корпоратив)
— Есть ли время? (улица — нет, юбиляр устаёт)
— Можно ли провести в шумном месте? (улица — только быстрые)
— Будет ли участвовать весь зал или только добровольцы?
```

**Матрица переноса конкурсов:**

| Конкурс | Свадьба | Корпоратив | Юбилей | Улица | Детский |
|---|---|---|---|---|---|
| «Кто лучше знает пару» | Да | Нет (напряжение) | Да (переделать) | Нет | Нет |
| «Угадай по фото» | Нет | Нет | Да | Нет | Нет |
| «Собери пирамиду» | Да | Да | Да | Да (быстро) | Да |
| «Хлопок на три» | Да | Да | Да | Да | Да |
| «Раз, два, три» | Да | Спорно | Да | Да | Да |
| «Гонки» | Да | Да | Спорно | Да | Да |
| «Лицо в очко» | Нет | Нет | Да | Нет | Да |
| «Собери слово» | Да | Да | Да | Спорно | Спорно |
| «Аукцион» | Спорно | Да | Нет | Нет | Нет |

**Шаг 4. Перепишите тосты.**

Тосты — это ядро юбилея, украшение свадьбы, формальность на корпоративе. Перепишите вводные фразы, оставьте структуру.

**Шаг 5. Проверьте тайминг.**

```
Свадьба: 4–6 часов
Корпоратив: 3–5 часов
Юбилей: 3–4 часа
Улица: 30–90 минут
Детский: 1,5–2 часа активной части
```

**Шаг 6. Уберите лишнее.**

Для каждого формата есть блоки, которые в нём лишние:

```
Свадьба:     убрать корпоративные «номера», длинные видео
Корпоратив:  убрать личные тосты, семейные конкурсы
Юбилей:      убрать шумные конкурсы, длинную официальную часть
Улица:       убрать тосты, длинные фразы, всё «интимное»
Детский:     убрать тосты, длинные поздравления, сложные правила
```

## Практический пример: из юбилея в корпоратив

**Исходник: юбилей, 30 гостей**

```
00:00 — Сбор гостей
00:20 — Открытие (3 мин)
00:23 — Тосты (30 мин)
00:53 — Салют
00:56 — Торт (10 мин)
01:06 — Спикер-конкурс «Угадай по фото» (10 мин)
01:16 — Свободное время (40 мин)
01:56 — Финал (5 мин)
```

**Пересборка в корпоратив, 60 гостей**

| Юбилей | → | Корпоратив | Что изменилось |
|---|---|---|---|
| Открытие (3 мин) | → | Открытие (7 мин) | + речь руководителя, программа |
| Тосты (30 мин) | → | Награждения (25 мин) | Тосты → номинации, темп выше |
| Салют (1 мин) | → | Общий тост (2 мин) | Формальнее |
| Торт (10 мин) | → | Кофе-брейк (15 мин) | Вместо торта — перерыв |
| Спикер-конкурс (10 мин) | → | Викторина по компании (10 мин) | Тема изменена |
| Свободное время (40 мин) | → | Активная часть (40 мин) | Конкурсы, фото |
| Финал (5 мин) | → | Финал (7 мин) | Итоги, благодарность |

**Что осталось без изменений:** механика открытия, представление людей, финал с мягким приземлением, работа с залом.

**Время пересборки:** 30 минут.

## Профиль формата: заполните для себя

Сделайте такую карточку для каждого формата, который планируете брать:

```
ФОРМАТ: [название]

Главный герой: _______________
Тон: _______________
Темп: _______________
Длина фразы: _______________
Юмор: _______________
Тайминг: _______________
Техника: _______________
Тосты: _______________
Конкурсы (3 рабочих): _______________
Главный риск: _______________
Ошибка новичка в этом формате: _______________
```

Когда карточки заполнены, пересборка сценария занимает 15 минут вместо 3 часов.

## Универсальные ошибки адаптации

**Ошибка 1. Менять структуру, а не только слова.**

Не нужно переписывать всё. Меняется герой, тон, длина фраз. Структура остаётся.

**Ошибка 2. Оставлять юмор из другого формата.**

Шутка, которая работает на свадьбе («а когда жених женился, он...»), может быть неуместна на корпоративе. Проверяйте юмор на уместность.

**Ошибка 3. Забывать про героя.**

Корпоративный сценарий, где никто не упоминает компанию — это не корпоративный сценарий.

**Ошибка 4. Не менять тайминг.**

Детский праздник в 4 часа — провал. 15-минутный юбилей — тоже провал.

**Ошибка 5. Не убирать лишнее.**

Конкурс «Угадай по фото» на корпоративе — неуместен и создаёт неловкость.

## Практика урока

**Задание 1. Таблица различий (15 минут).** Заполните таблицу различий для 5 форматов по образцу. Не смотрите в урок, восстановите по памяти.

**Задание 2. Матрица конкурсов (20 минут).** Заполните матрицу переноса конкурсов: 9 конкурсов × 5 форматов. Пометьте «да», «нет», «переделать».

**Задание 3. Пересборка (40 минут).** Возьмите свой сценарий одного формата. Пересоберите его в другой формат по 6 шагам. Запишите, что получилось и сколько времени заняло.

**Задание 4. Профили форматов (20 минут).** Заполните карточки для 3 форматов, которые планируете брать.

**Задание 5. Ошибки (10 минут).** Выпишите 5 ошибок адаптации из собственного опыта или примеров.

## Домашнее задание недели

1. **Пересборка сценария.** Возьмите один сценарий и пересоберите в другой формат. Результат — полный сценарий.

2. **Три профиля форматов.** Заполнены карточки.

3. **Матрица конкурсов.** Заполнена для 5 форматов.

4. **Проверка на уместность.** Возьмите все шутки из своих сценариев и проверьте каждую: где уместна, где нет.

5. **Четыре готовых сценария.** К этому моменту у вас должно быть 4 сценария: свадьба, корпоратив, юбилей, уличное событие. Если какого-то нет — сделайте в этот раз.

Модуль закрыт, если:

- [ ] У вас есть полный сценарий свадьбы
- [ ] У вас есть полный сценарий корпоратива
- [ ] У вас есть полный сценарий юбилея
- [ ] У вас есть полный сценарий уличного события
- [ ] У вас есть сценарий детского праздника
- [ ] Заполнены карточки профилей форматов
- [ ] Заполнена матрица конкурсов
- [ ] Вы умеете пересобрать сценарий за 40 минут
- [ ] Каждый шутка проверена на уместность в каждом формате

**Итоговое задание модуля 5. Пять сценариев.**

Соберите пять готовых сценариев в одной папке. Каждый должен содержать:

```
1. Карточка профиля формата
2. Каркас из 7 блоков
3. Минутная сетка с резервом
4. Ключевые тексты (открытие, акцентный блок, финал)
5. Список конкурсов с описанием
6. Карточки для мероприятия

Объём: 3–5 страниц на формат
```

**Это ваш рабочий комплект.** На любом мероприятии вы берёте нужный сценарий, адаптируете под конкретных людей и имена — и работаете.

## Вопрос для самопроверки

**Вам предлагают вести корпоратив, а ваш единственный опыт — юбилея. Стоит ли брать?**
Ожидаемый ответ: да, если формат вам понятен по структуре. Корпоратив отличается от юбилея тоном (деловее), регламентом (жёстче) и отсутствием личных тостов. Структура та же: сбор → открытие → официальная часть → активная часть → финал. Что нужно доделать: 1) Заполнить карточку профиля корпоратива. 2) Взять свой юбилейный сценарий и пересобрать: тосты заменить награждениями, спикер-конкурс заменить викториной, свободное время оставить, финал сделать деловым. 3) Убрать всё личное и семейное. 4) Отработать формулировки награждений — их вы будете произносить дословно. 5) Прогнать вслух. Если всё это — 1–2 часа работы, а съёмка корпоратива стоит в 2–3 раза больше юбилея, то брать выгодно. Отказ имеет смысл только если вы не готовы к жёсткому регламенту и необходимости отвечать за чужие спикеров.
