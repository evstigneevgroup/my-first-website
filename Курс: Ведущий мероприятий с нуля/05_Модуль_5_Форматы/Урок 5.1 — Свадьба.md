# Урок 5.1. Свадьба: банкетная часть, тосты, режиссура

Первый урок модуля 5. Первый полноценный сценарий курса.

## Специфика свадьбы

**Что делает свадьбу сложной:**

- Много гостей, незнакомых между собой
- Эмоции высокие, все волнуются
- Пара — главные герои, но они не могут говорить (они в центре внимания)
- Регламент гибкий: тайминг меняется на ходу
- Речи родителей — самые эмоциональные моменты, их нельзя завалить

**Что делает свадьбу простой:**

- Все знают, зачем они здесь
- Формат понятен: тосты, танцы, конкурсы
- Пара можно вовлекать в сценарий
- Много поводов для вовлечения зала

## Структура свадебного вечера

```
ВСТРЕЧА ГОСТЕЙ (вручение приглашений, гардероб, Welcome-напитки)

СБОР В ЗАЛ + ОТКРЫТИЕ (5–7 мин)
   └─ Первый танец молодожёнов
   └─ Приветственный круг (свадебный, тосты родителей входят)
   └─ Молодое вино, шампанское
ПЕРВЫЙ ТАНЕЦ И ОБЪЯВЛЕНИЕ (5–8 мин)

СВАДЕБНЫЙ КРУГ / БАНКЕТНАЯ ЧАСТЬ (40–60 мин)
   └─ Свадебный распорядитель за столом
   └─ Тосты (2–5)
   └─ Игры и конкурсы (2–3)
   └─ Свадебная игра «Девочка/Мальчик»
   └─ Игра с подвязкой
   └─ Обручальные кольца на лестнице

ТАНЦЫ И ПЕРЕРЫВЫ (60–120 мин)
   └─ Торт (10–15 мин)
   └─ Прогулка молодожёнов (20–30 мин)
   └─ Танцевальная программа
   └─ Поздравления от коллег и друзей

ФИНАЛЬНЫЙ БЛОК (7–10 мин)
   └─ Сбор зала
   └─ Эмоциональное слово
   └─ Финальный тост
   └─ Прощание, передача «эстафеты» гостям
```

## Роль ведущего на свадьбе: режиссура

Ведущий на свадьбе — это режиссёр, а не рассказчик.

**Что это значит:**

1. **Он держит тайминг.** Не «программа идёт», а «мы идём по плану, потому что я слежу».

2. **Он переключает зал.** Когда гости переговариваются — он переключает. Когда гости устали от тостов — он даёт паузу.

3. **Он представляет.** Каждый тост он вводит. Каждый конкурс он объявляет. Каждый «номер программы» он анонсирует.

4. **Он спасает.** Опоздал фотограф, сломался микрофон, кто-то уснул — он не даёт вечеру развалиться.

5. **Он держит в себе тайну.** Не говорит лишнего: не объявляет сюрпризов, не спойлерит, не пересказывает то, что пара хочет сохранить.

## Формула «Дом, который строил муж»

Один из главных конкурсов на свадьбе. Суть: друзья и родные строят «дом» (конструкцию из воздушных шаров или картонных блоков) для молодожёнов.

**Сценарий ведущего:**

1. **Подготовка (5–10 мин, ведущий не участвует):** попросите 2–3 пары молодых людей, ознакомьтесь с инструкцией, распределите роли, дайте материалы.

2. **Объявление конкурса:**
```
«Друзья, мы с вами строим дом. / Точнее — дом для наших молодожёнов. /
Будем строить из воздушных шаров — / тот, кто построит самый прочный,
выиграет главный приз. /
Но у меня для вас сюрприз: строить будем не одни. / Строители уже
подготовили основу — а вам нужно достроить. /
Вот эти [3 человека] уже в деле. / Остальные — присоединяйтесь!
/ Работаем 3 минуты. / Потом проверим, чей дом выдержит / вес
новорождённого. / Не спрашивайте, откуда я это знаю. / Погнали!»
```

**Ключевой момент — последняя фраза.** Именно она делает конкурс смешным: аллюзия на будущее, с интригой.

3. **Ход конкурса:** помогайте, подбадривайте, тайминг. «Две минуты! / Одна минута! / 30 секунд! / Стоп!»

4. **Проверка:**
```
«Так, проверяем! / Вот этот дом весит [X], / этот — [Y]. /
Кто выиграл? / [Название команды]! / Аплодируем!»
```

5. **Вручение приза.**

## Формула «Обручальные кольца на лестнице»

Классическая игра. Пара стоит на полуточке. Ведущий даёт инструкцию.

**Сценарий:**

1. **Подготовка:** свадебные кольца привязаны к ниточке. Один конец нитки — ведущему, другой — пара в руках.

2. **Объявление:**
```
«[Имя] и [Имя], встаньте сюда, на полочку. /
У меня в руках — ваши обручальные кольца. /
А в руках у вас — кончик верёвочки. /
Моя задача — накинуть кольца вам на руки. /
Не на голову — именно на руки. / Не на шею. / На руки. /
Правило одно: / кольца не должны коснуться ничего, /
кроме ваших рук. / Ни пола, ни стен, ни моей руки. / Понятно? / Готовы?»
```

3. **Ход игры:** давайте инструкцию 2–3 минуты, не подсказывая. Зал болеет, все смеются.

4. **Финал:**
```
«Так! / Поздравляю! / Обручальные кольца на месте. /
А теперь — за то, чтобы всё сложилось! / Горько!»
```

**Почему это работает:** зал вовлечён, все смеются, никто не скучает, зал играет вместе с парой.

## Формула «Свадебная игра — кто папа/мама»

Классическая игра: на улице стоят плакаты «Мама» и «Папа». Пара с завязанными глазами подходит к одному из знаков и оставляет свою метку. Потом открывают глаза — сколько меток на «Маме», столько и детей.

**Важные правила игры:**

1. Пара должна принять участие осознанно. Предупредите заранее.
2. Если пара не хочет — не настаивайте (урок 4.3).
3. Игра длится 3–5 минут, не больше.
4. Комментируйте мягко и тепло: «Смотрите, что получается — вот это будущая мама четверых!»

## Момент первого танца: режиссура

Это самый важный момент вечера. Работа ведущего:

**1. Убрать всё лишнее.**

Перед танцем: приглушить свет, выключить яркий свет над столами, поставить гардину или выйти вперёд, убрать со сцены лишние предметы.

**2. Сцена:**
```
«Друзья, прошу минуту тишины. / (пауза 3 сек, зал замолкает)
Сейчас на танцполе — люди, ради которых мы все здесь собрались. /
Посмотрите на них. / Запомните этот момент. /
Потому что через двадцать лет они будут рассказывать
о нём детям. /
(пауза 2 сек)
Внимание — первый танец молодожёнов! /
Музыка!»
```

**3. Во время танца — минимум слов.**

Молчите или говорите одно-два предложения, если это уместно:

```
«Первый танец — это про то, / что всё только начинается»
```

**4. После танца — эмоциональный момент:**
```
«(пауза 3 сек, смотрите на пару)
Ну... / вот что бывает, когда всё сложилось. /
Давайте поднимем бокалы! / За молодых! / Горько!»
```

**Важно:** после танца дайте залу отреагировать. Не заполняйте паузу. Реакция зала — часть момента.

## Свадебные тосты: как вводить

**Структура ввода тоста:**

```
1. ПОДВОДКА (20–30 сек) — подготовить зал, создать настроение
2. ПРЕДСТАВЛЕНИЕ (30 сек) — кто говорит, одна деталь о нём
3. ПРИГЛАШЕНИЕ (5 сек) — «Слово — ...»
4. ПАУЗА (3 сек) — тишина, зал приготовился
5. [ГОСТЬ ГОВОРИТ]
6. ДОБИВКА (20–30 сек) — ваши слова после тоста
```

**Примеры представлений:**

```
Отец невесты:
«Друзья, есть человек, который всю жизнь говорил одно и то же:
“Делай как правильно”. / Завтра он скажет это в третий раз — /
вслух, перед всеми. / Слово — [Имя]!»
```

```
Мать жениха:
«Мне сложно говорить о ней три минуты — / я три года учила
её держать вилку. / Слово — мама!»
```

```
Друг пары:
«Этот человек был свидетелем на их первой свадьбе — /
они тогда поженились в джинсах. / Слово — [Имя]!»
```

**После тоста — добивки:**

Если тост смешной:
```
«Ну, я не знаю, кто из вас после этого будет есть вторую порцию»
```

Если тост трогательный:
```
«(пауза 2 сек) / Что ж мне сказать... / Скажу только: спасибо»
```

Если тост неловкий (забыл, что сказать):
```
«Так, [Имя] вдохновение прибережёт на следующий тост. /
А сейчас — музыка! / Танцуем!»
```

## Момент «Свадьба! / Горько!»

**Разбор:** «Горько» — это традиция, не обязательство. Ваша задача — создать момент, а не контролировать количество бокалов.

**Как вести:**

```
«Друзья, молодожёны выпили свой бокал — /
Теперь у нас два варианта: /
либо мы тоже пьём, либо все голодают. /
Я за первый! / Проздравляю молодых! / Горько!»
```

**Если гости отказываются пить:**

```
«Что ж, не будем настаивать — /
молодожёны, ваши бокалы мы всё равно заберём. /
А все, кто хочет поддержать традицию — поднимаем бокалы»
```

**Темп:** не делайте «горько» чаще, чем раз в 20–30 минут. Иначе оно перестаёт работать и превращается в обязанность.

## Практика урока

**Задание 1. Сценарий (30 минут).** Напишите полный сценарий свадьбы на 40 гостей: 7 блоков, тайминг, ключевые фразы. Объём — 3 страницы.

**Задание 2. Момент первого танца (15 минут).** Напишите текст подводки к первому танцу (2–3 фразы) и фразу после. Проговорите вслух.

**Задание 3. Представления (20 минут).** Напишите 5 представлений для свадьбы: отец, мать, друг, коллега, брат/сестра.

**Задание 4. Два конкурса (25 минут).** Опишите 2 конкурса полностью: «Дом, который строил муж» и «Кольца на лестнице». С подводками, правилами, ходом, подведением.

**Задание 5. Тосты-имитация (15 минут).** Проговорите вслух: представление + приглашение + добивка. Три раза.

## Домашнее задание недели

1. **Полный сценарий свадьбы** — 3 страницы, с таймингом и ключевыми фразами.

2. **Все фразы подводу — проговорены вслух.** Минимум 5 раз каждая.

3. **Момент первого танца** — отработать с выходом, паузой, музыкой.

4. **Пять представлений** — написаны и проговорены.

5. **Два конкурса** — описаны, правила не длиннее трёх, проговорены.

6. **Адаптация под ваше мероприятие:** заменить имена, конкурсы на свои, добавить или убрать блоки.

## Критерии проверки

- [ ] Полный сценарий свадьбы на 3 страницы, с таймингом
- [ ] 7 блоков присутствуют, включая застройку
- [ ] Текст подводки к первому танцу написан и проговорен
- [ ] 5 представлений написаны и проговорены
- [ ] 2 конкурса описаны полностью, правил не больше трёх
- [ ] Есть текст момента «горько» и вариант для отказа пить
- [ ] Сценарий адаптирован под ваше реальное мероприятие (имена, конкурсы)

## Что запомнить

1. Ведущий на свадьбе — режиссура, а не рассказ.
2. 4 главных блока: сбор + открытие, банкетная часть с тостами, танцы с тортом, финал.
3. Первый танец: убрать лишнее → подводка → пауза → «Музыка!» → молчание → добивка.
4. Тост: подводка → представление → «Слово — ...» → пауза 3 сек → гость → добивка.
5. Конкурсы работают, если есть интрига в финале («проверим дом на вес новорождённого»).
6. «Горько» — раз в 20–30 минут, не чаще.

## Вопрос для самопроверки

**Отец невесты, выпивший, встаёт и говорит тост, который никто не ожидал — 8 минут вместо 4. Зал шумит, но слушает. Ваши действия?**
Ожидаемый ответ: 1) Не прерывать. Тост отца невесты на свадьбе — эмоциональный момент, и если зал слушает, это работает. 2) Не показывать усталость, стоять спокойно, смотреть на зал, не в телефон, не переминаться. 3) Параллельно (в голове или шёпотом помощнику) — посчитайте, сколько минут вышло сверх плана, и решите, где компенсировать. Мягкие блоки: сократить один конкурс на 5 минут или добавить 5 минут к танцам. 4) Когда тост закончится — пауза 2–3 секунды, дайте залу отреагировать (аплодисменты, слезы). 5) Добивка, которая связывает: «Спасибо, [Имя]. / Вот что бывает, когда дочь — главное в жизни. / Давайте за здоровье наших родителей!» 6) Записать в дневник: тайминг речевого блока на свадьбе нужно закладывать с запасом 50%, потому что эмоциональные тосты всегда длиннее расчётных. Важно: пауза после тоста — не ваша проблема, а часть вечера. Не торопите зал.
