# Шаблон минутной сетки

Бланк тайминга по минутам. Заполняется вместе со сценарием (урок 2.2).

## Что такое минутная сетка

Сетка — это не план («в 19:00 тосты»), а точный тайминг с резервом. Она нужна для трёх вещей:

1. **Вы не теряете блок**, потому что помните, что следующий и когда.
2. **Вы видите опоздание заранее** — по сетке, а не по ощущению.
3. **У вас есть резерв**, который можно потратить, а не паниковать.

## Шапка

```
МЕРОПРИЯТИЕ: _______________
ДАТА: _______________ НАЧАЛО: ____ : ____  ЗАВЕРШЕНИЕ: ____ : ____
ДЛИТЕЛЬНОСТЬ ВЕЧЕРА: ____ ч
РЕЗЕРВ ОБЩИЙ: ____ мин (10% от длительности официальной части)
КОНТРОЛЬНЫЕ ТОЧКИ: ____ : ____ , ____ : ____ , ____ : ____
```

## Три контрольные точки

Контрольная точка — момент, когда вы смотрите на часы и сверяетесь с планом. Их нужно три за вечер.

| Точка | Время | Что должно происходить | Отклонение, которое допустимо |
|---|---|---|---|
| КТ-1 | ____ : ____ | __________ | ±3 мин |
| КТ-2 | ____ : ____ | __________ | ±5 мин |
| КТ-3 | ____ : ____ | __________ | ±5 мин |

**Правило:** если отклонение больше допустимого — резать нужно следующий мягкий блок (паузу, свободное время, конкурс), а не акцентный.

## Итог по сетке

```
Время по плану:              ____ ч ____ мин
Резерв заложен:              ____ мин
Время аренды площадки:       ____ ч
Мой рабочий день:            ____ : ____ — ____ : ____ (с дорогой)
Число мероприятий в месяц:   ____ (потолок 4–6, урок 6.3)
```

## Проверка

- [ ] Сетка заканчивается минимум за 30 минут до конца аренды
- [ ] Резерв есть в каждом блоке, не только в одном
- [ ] Есть один большой резерв (15–20 мин) в свободной части
- [ ] Три контрольные точки расставлены и записаны в карточке
- [ ] Есть технические паузы (переходы) — без них блоки «склеиваются»
- [ ] Сумма времени блоков совпадает с длительностью вечера
- [ ] Я знаю, какой блок резать, если отстаю

## Если сетка разваливается в процессе

Порядок действий (урок 2.2):

```
1. Отстали на 5–10 мин   → урезать паузы и свободное время
2. Отстали на 10–20 мин  → сократить один конкурс, не акцентный блок
3. Отстали на 20+ мин    → пропустить блок целиком, предупредить организатора
4. Устали по времени      → сократить финал, не акцентный момент
5. Ничего не помогает    → объявить программу заново и уйти в свободное время
```

**Что резать нельзя:** акцентный блок (первый танец, награждение, юбилейный тост), финальный тост, открытие (если уже начали — не бросать на полуслове).
