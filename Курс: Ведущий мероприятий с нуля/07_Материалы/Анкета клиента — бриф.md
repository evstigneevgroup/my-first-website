# Анкета клиента (бриф)

Бланк для первого созвона. Заполняется до того, как вы назовёте цену. Без заполненной анкеты вы гадаете 4 часа подряд (урок 6.3).

**Правило:** созвон 20–30 минут, не по телефону «на ходу», а спокойно, с ручкой. Все ответы — в анкету. На созвоне вы не продаёте, а выясняете, сможете ли вы это сделать и сколько это стоит.

## Шапка

```
ЗАКАЗ № ____          ДАТА СОЗВОНА: _______________
КЛИЕНТ: __________________________  КОНТАКТ: __________________
ФОРМАТ: __________________  ДАТА МЕРОПРИЯТИЯ: _______________
ГДЕ УЗНАЛ О ВАС: __________________  РЕКОМЕНДАЛ: __________________
```

## Блок 8. Ловушки, на которые нужен ответ

Задайте эти вопросы вслух. Молчаливый «нет» — это «да».

```

Будет ли мероприятие без вас, если вам придётся уйти сразу после финала?
_______________

Есть ли запрет на музыку / алкоголь / определённые темы: _______________

Есть ли у вас «особый гость», о котором нужно знать заранее: _________
```

## Решение после созвона

```
ФОРМАТ: ______________
ЭТО МОЙ ФОРМАТ?           Да / Нет / С оговоркой: _______________
ТАЙМИНГ ОЦЕНИВАЮ: ____ ч официальной части, реально ____ ч
СЛОЖНОСТЬ: 1 / 2 / 3 / 4 / 5 (1 — юбилей дома, 5 — корпоратив на 150 гостей)

ЦЕНА (по формуле урока 6.1):
Часы: ____ × Ставка: ____ ₽ = ____ ₽
Коэффициент: ____ = ____ ₽
ИТОГО ПРЕДЛОЖИТЬ: ____ ₽

СОГЛАСИТЬСЯ, ЕСЛИ: клиент согласится на ____ ₽ и ______________
ОТКАЗАТЬСЯ, ЕСЛИ: сумма ниже ____ ₽ или ______________

КОНТРОЛЬНЫЙ ПУНКТ: ____ : ____ о начале подготовки сценария
```

## Вопросы, которые этот шаблон закрывает

- [ ] Я знаю, сколько у меня гостей, времени и техники
- [ ] Я знаю имена героев и то, что нельзя упоминать
- [ ] Я знаю, есть ли регламент и насколько он жёсткий
- [ ] Я знаю реальный бюджет клиента
- [ ] Я вижу риски, которые не обсудили
- [ ] Я могу назвать цену или отказаться — с аргументом
- [ ] У меня есть контрольный пункт (дата, когда пишу сценарий)
