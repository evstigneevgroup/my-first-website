# Карточки профилей форматов

Пять бланков — по одному на каждый формат. Формат — из урока 5.6. Заполняются один раз и обновляются по мере накопления опыта.

**Зачем это:** когда вы знаете профиль формата, пересборка сценария занимает 15 минут вместо 3 часов. Профиль — это не описание жанра, а ваши рабочие настройки: тон, длина фраз, юмор, тайминг, техника, риски.

---

## ПРОФИЛЬ 1. СВАДЬБА

```
Главные герои:        двое — жених и невеста (+ родители, друзья, коллеги)
Тон:                  тёплый, праздничный, с юмором, но без вульгарности
Темп:                 средний → разгонный к танцам → торжественный у торта
Длина фраз:           10–15 слов
Интонация:            меняется каждые 2–4 минуты, пик — первый танец и тост
Юмор:                 умеренный, про молодых, без личных историй третьих лиц
Конкурсы:             2–3, сложные, с подготовкой (10–15 мин каждый)
Тосты:                3–5, сорок: родители → друзья → коллеги
Акцентный блок:       первый танец молодожёных, 6 мин
Тайминг:              гибкий, можно растянуть на 20–30 мин
Техника:              микрофон, колонка, 2–3 музыкальных блока,
                      свет для торта, микрофон в зале для тостов
Главный риск:         эмоции (плач, срывы), опоздание, дождь (если уличная)
Ошибка новичка:        монолог вместо ведения зала; конкурс в неподходящий момент;
                      читает тост гостя вместо своей подводки
Первое действие ведущего после финала: ______________
```

## ПРОФИЛЬ 2. КОРПОРАТИВ

```
Главные герои:        компания, команда, руководитель, награждаемые
Тон:                  деловой, уважительный, тёплый, без личных историй
Темп:                 разгонный в начале → торжественный в награждении
Длина фраз:           10–20 слов, фразы короче в официальной части
Интонация:            ровная и собранная, паузы — точные
Юмор:                 минимальный, только в активной части, без подколов
Конкурсы:             1–2 простых, интеллектуальных (викторина о компании)
Тосты:                1–2, обычно от руководителя, короткие
Акцентный блок:       награждение сотрудника, 3–5 мин
Тайминг:              жёсткий, регламент согласован заранее
Техника:              микрофон, колонка, экран для презентаций, звук для
                      заставок, микрофоны для спикеров
Главный риск:         нарушение регламента, скука в официальной части,
                      перебор по времени
Ошибка новичка:        пытается развлечь в официальной части; не удерживает
                      регламент; не умеет вывести неуверенного спикера
Что нужно уметь:       объявлять номинации дословно, диспетчерировать время
Первое действие ведущего после финала: ______________
```

## ПРОФИЛЬ 3. ЮБИЛЕЙ И ДЕНЬ РОЖДЕНИЯ

```
Главные герои:        один человек (иногда два — пара)
Тон:                  личный, тёплый, чуть ироничный
Темп:                 медленный, без спешки
Длина фраз:           8–12 слов
Интонация:            мягкая, «соседская», без пафоса
Юмор:                 умеренный, про юбиляра, только с его разрешения
Конкурсы:             1–2 спикерских (угадай по фото, вспомни случай)
Тосты:                3–5, личные, от самых близких
Акцентный блок:       юбилейный тост, 3–5 мин
Тайминг:              гибкий, вечер может быть длиннее заявленного
Техника:              часто без техники; если зал большой — микрофон и колонка
Главный риск:          усталость героя к третьему часу, чрезмерная
                      сентиментальность, слишком длинные тосты
Ошибка новичка:        перетягивает внимание на себя; юбиляр устал, а вы
                      продолжаете программу
Что нужно уметь:       чувствовать усталость героя и убирать программу
Первое действие ведущего после финала: ______________
```

## ПРОФИЛЬ 4. ПУБЛИЧНОЕ СОБЫТИЕ (УЛИЦА)

```
Главные герои:        толпа, спикеры, город
Тон:                  энергичный, короткий, громкий
Темп:                 быстрый
Длина фраз:           5–7 слов
Интонация:            максимальная, «уличная», без тонкостей
Юмор:                 активный, короткий, понятный с расстояния
Конкурсы:             1–2 быстрых (30–90 сек), только в толпе у микрофона
Тосты:                нет
Акцентный блок:       главный номер / выступление, 5–10 мин
Тайминг:              очень жёсткий, всё по минутам, регламент мэрии/площадки
Техника:              микрофон (часто беспроводной и один), колонка,
                      петличка, резервный питающий блок
Главный риск:          ветер, шум, дождь, расстояние до толпы, нет розетки
Ошибка новичка:        стоит в одной точке и говорит длинными фразами;
                      не двигается к толпе; забывает про ветер в микрофон
Что нужно уметь:       ходить, ставить «якоря», работать без звука
Первое действие ведущего после финала: ______________
```

## ПРОФИЛЬ 5. ДЕТСКИЙ ПРАЗДНИК

```
Главные герои:        дети 4–10 лет, родители, именинник
Тон:                  весёлый, простой, добрый, без сложных слов
Темп:                 быстрый, с паузами на реакцию детей
Длина фраз:           6–10 слов, короткие команды
Интонация:            яркая, «сказалка», часто обращение к каждому ребёнку
Юмор:                 простой, добрый, без страшных и жестоких шуток
Конкурсы:             3–4 коротких (5–7 мин), с движением и реквизитом
Тосты:                нет, есть слова родителей
Акцентный блок:       вручение подарка / именинный торт, 5 мин
Тайминг:              жёсткий по длительности, 1,5–3 часа максимум
Техника:              колонка, микрофон, аксессуары; розетка часто далеко
Главный риск:          дети перевозбуждены, ребёнок не хочет участвовать,
                      родители вмешиваются, долгий вечер
Ошибка новичка:        конкурс «для взрослых» детям; не даёт детям роль;
                      не замечает, что ребёнок перегружен
Что нужно уметь:       вовлекать, а не развлекать; давать роль; быстро менять
                      формат
Первое действие ведущего после финала: ______________
```

## Что отслеживать в профиле

Через 5–10 выступлений в формате допишите в профиль:

```
Что сработало лучше всего: _____________________________________
Что провалилось: _____________________________________________
Сколько времени реально занял вечер: ____ вместо ____
Средняя цена: ____ ₽
Сколько раз отказывались: ____ из ____
Источники заказов: _________________________________________
```

**Профиль — живой документ.** Если после 10 мероприятий юбилей даёт вам 2 заказа, а корпоратив 0 при вдвое большей цене, ваш выбор очевиден, даже если юбилей приятнее.
