# Чек-лист комплекта техники

Бланк для проверки комплекта перед выездом и на площадке. Формат — из модуля 3 (уроки 3.1–3.5).

**Когда заполняется:** дважды. Первый раз — накануне вечером, дома. Второй — на площадке, после подключения, но до прихода гостей.

---

## Чек-лист А. Дома, за день до мероприятия

```
ТЕХНИКА
[ ] Основной микрофон — заряжен на 100%
[ ] Запасной микрофон — заряжен на 100%
[ ] Микрофонная батарея / Powerbank — заряжен
[ ] Колонка или микшер + колонка — проверены
[ ] Удлинитель 5 м — в сумке
[ ] Переходники (6,3 мм / mini-XLR / 3,5 мм) — в сумке
[ ] Провод микрофона — не переломан

МУЗЫКА
[ ] Плейлист загружен офлайн
[ ] Телефон / ноутбук заряжен на 100%
[ ] Все треки на месте, 3 ключевых проверены воспроизведением
[ ] Отключена автоматическая блокировка экрана
[ ] Наушники в сумке

КАРТОЧКИ И ДОКУМЕНТЫ
[ ] Сценарий распечатан (3–5 страниц)
[ ] Карточки написаны от руки и сфотографированы
[ ] Анкета клиента с именами
[ ] Договор и квитанция об оплате (если оплата в день)
[ ] Реквизиты для оплаты / реквизиты для счёта

СУМКА ВЕДУЩЕГО
[ ] Телефон заряжен, паспорт, ключи
[ ] Ручка, блокнот
[ ] Фонарик
[ ] Бутылка воды
[ ] Блокнот с аварийными фразами (урок 4.5)
[ ] Пакет с реквизитом для конкурсов: ____________
[ ] Беру на мероприятие: ____________ (список реквизита)
[ ] Касса / терминал для оплаты, если расчёт на месте
```

## Чек-лист Б. На площадке (за 2 часа до начала)

```
ПОДКЛЮЧЕНИЕ
[ ] Розетка найдена, удлинитель подключён
[ ] Колонка поставлена в правильную точку (не в углу, не за спиной у сцены)
[ ] Микрофон включён, звук есть
[ ] Громкость выставлена: в дальнем углу слышно, вблизи не оглушает
[ ] Я слышу себя в наушниках
[ ] Проверка из дальнего угла: слова различимы, музыка не мешает
[ ] Тест на 30 секунд: говорю зал — все ли слышат

МУЗЫКА
[ ] Плейлист идёт с устройства
[ ] Громкость фона: 3–4 деления, не перекрикивает разговор
[ ] Переход между треками не слышен со сцены
[ ] Зал ожидает: фоновая музыка играет

ЗАЛ
[ ] Где стою: ____________
[ ] Откуда я слышу себя: ____________
[ ] Видно ли героев, столы, выход на сцену
[ ] Свет: есть ли, включается ли, достаточно ли
[ ] Танцпол: свободен, техника не стоит на пути
[ ] Колонка не стоит в проходе

КОМУНИКАЦИЯ
[ ] Организатор найден, инструктаж получен
[ ] Порядок выступлений подтверждён устно и в карточке
[ ] Кто говорит, когда, сколько минут
[ ] Кто отвечает за музыку (вы или площадка)
[ ] Точка силы: [время] — [что], я на месте
[ ] Точка «тяжёлого решения» (конфликт, отмена): кто помогает
[ ] Контактный телефон организатора сохранён
[ ] Телефон площадки / дежурного сохранён
```

## Чек-лист В. Перед финальным «выходом» в зал

```
[ ] Зал наполняется, шум управляем
[ ] Герои на месте (проверить лично)
[ ] Микрофон на заряде (если беспроводной)
[ ] Карточки в кармане
[ ] Сценарий на телефоне
[ ] Музыка для первого блока готова, нажатие проверено
[ ] Я не спешу, дышу, помню первую фразу
```

## Запасной комплект

```
Что берётся всегда, даже если «не понадобится»:
[ ] Запасной микрофон
[ ] Powerbank
[ ] Удлинитель
[ ] Переходник 6,3 мм ↔ 3,5 мм
[ ] Петличка на случай, если динамика отказал
[ ] Наушники
[ ] Фонарик
[ ] Удлинитель с тройником (для площадки с одной розеткой)
```

## Если звук не работает: 60 секунд

Порядок действий из урока 3.4:

```
0–10 сек   Не паниковать. Запасной микрофон уже в руке.
10–20 сек  Проверить: батарея включена, разъём до конца, кабель не пережат.
20–35 сек  Проверить: колонка включена, вход выбран правильный.
35–50 сек  Выключить-включить: питание колонки.
50–60 сек  Перейти в режим 3 (без микрофона) и сказать залу одну фразу:
           «Друзья, техника решила отдохнуть. Продолжим без неё,
           только я буду ближе к вам».
```

**Чего не делать:** стучать по колонке, кричать «ААА», бегать с проводами на виду у гостей, разбираться дольше 2 минут. Зал на 2 минуты забудет о проблеме, если вы переключились на формат без звука.

## Что делать после сбоя

```
Микрофон сел →     встать ближе, перейти в режим 3, обходить столы
Микрофон сломал →  запасной; нет запасного → режим 3, обход
Колонка молчит →   3 попытки переподключения, затем режим 3
Колонка и микрофон → 3 минуты попыток → план Б целиком:
                    работа без звука, сокращение официальной части,
                    перенос акцентных блоков на финал
Свет погас →       фонарик для тоста, продолжение по карточкам
```

## Проверка комплекта после вечера

```
[ ] Всё на месте, ничего не забыто на площадке
[ ] Техника выключена, кабели убраны
[ ] Батареи поставлены на зарядку
[ ] Есть повреждения (кабель, корпус) — описать и починить
[ ] Если техника ломалась: записать, что именно, и купить/заменить
[ ] Фото поломки — в заметки, чтобы не забыть
```
