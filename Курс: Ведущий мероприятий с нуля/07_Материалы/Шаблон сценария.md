# Шаблон сценария

Бланк полного сценария. Копируйте под конкретное мероприятие. Формат записи — из урока 2.6.

## Шапка

```
МЕРОПРИЯТИЕ: _______________
ФОРМАТ:     свадьба / корпоратив / юбилей / публичное / детский
ДАТА:       _______________
ВРЕМЯ:      начало ____ : ____ , финал ____ : ____
МЕСТО:      _______________
ГЛАВНЫЕ ГЕРОИ: _______________
КОЛИЧЕСТВО ГОСТЕЙ: ____
ВЕДУЩИЙ: _______________
ТЕХНИКА НА ПЛОЩАДКЕ: _______________
СВОЯ ТЕХНИКА: _______________
```

## Условные обозначения

```
[ДОСЛОВНО]     — произносится точно по тексту, учить наизусть
[СВОИМИ СЛОВАМИ] — структура обязательна, слова свои
[ИМПРОВИЗАЦИЯ] — заготовки нет, только тема и длина
[ДОБИВКА]      — фраза после чужого блока (тоста, номера)
[ПАУЗА 2 сек]  — пауза, не заполнять паразитами
[?]            — уточнить у организатора
[РЕЗЕРВ]       — время, которое можно потратить или сэкономить
[ТЕХНИКА]      — действие с музыкой/светом/звуком
```

## Сценарий

### Блок 0. Застройка (до гостей)

```
[__:__]  ЗАСТРОЙКА

       [__:__] Подключение микрофона, проверка звука (подойти в дальний угол)
       [__:__] Проверка музыки: 3 трека, громкость, смена
       [__:__] Согласование с организатором: порядок, тайминг, кто говорит
       [__:__] Обход зала: где стоять, где столы, где выход на сцену
       [__:__] Знакомство с ключевыми гостями: имена записаны
       [__:__] Проверка: имена героев, имена родителей, ключевые цифры
       [__:__] Точка силы: [время] — [что происходит], я должен быть готов
```

### Блок 1. Сбор гостей и запуск фона

```
[__:__]  СБОР ГОСТЕЙ                                резерв: ___ мин

       [ТЕХНИКА] Фоновая музыка: плейлист «фон» / конкретные треки
       [__:__] Встреча гостей у входа, фраза приветствия
       [__:__] Гости рассаживаются, наводка на зал
       [__:__] Сбор зала: [фраза-сбор], музыка приглушается
       [__:__] Проверка: герои на месте, микрофоны у ключевых людей
```

### Блок 2. Открытие (3–7 минут)

Формула: обращение → идентификация → контекст → крючок (урок 2.3).

```
[__:__]  ОТКРЫТИЕ

       [СВОИМИ СЛОВАМИ] Обращение: ______
       [__:__] Крючок, который удерживает зал в первые 90 секунд
       [ДОСЛОВНО] Имена героев: [полные имена и фамилии]. Не путать.
       [СВОИМИ СЛОВАМИ] Представление ведущего (30–60 сек)
       [СВОИМИ СЛОВАМИ] Программа вечера, 3–4 пункта
       [ПАУЗА 2 сек] Перед первым тостом
       [ДОБИВКА] Если герои волнуются: ______
```

### Блок 3. Официальная часть (20–60 минут)

```
[__:__]  ОФИЦИАЛЬНАЯ ЧАСТЬ                        резерв: ___ мин

       [__:__] Слово [роль 1]: [имя], [тема], [мин]
              [ДОБИВКА] Если коротко: ______
              [ДОБИВКА] Если дольше: ______
       [__:__] Слово [роль 2]: [имя], [тема], [мин]
              [ДОБИВКА] ______
       [__:__] Слово [роль 3]: [имя], [тема], [мин]
              [ДОБИВКА] ______
       [__:__] Мой акцентный блок здесь: [тема], [3–5 мин]
              [ДОСЛОВНО] Ключевые цифры/имена: ______
       [__:__] Свободное слово (2 мин): [как пригласить, не настаивая]

       [ВНИМАНИЕ] Кто ещё может выступить: ______
       [ВНИМАНИЕ] Регламент жёсткий / свободный: ______
```

### Блок 4. Свободная часть и перерывы

```
[__:__]  КОНКУРСНАЯ ПРОГРАММА                     резерв: ___ мин

       [__:__] Конкурс 1: [название]
              Что нужно: [реквизит], [сколько человек], [сколько минут]
              Что вручаем: ______
              Подводка: ______
              Итог: ______
       [__:__] Пауза / свободный танец: ___ мин
       [__:__] Конкурс 2: [название]
              Что нужно: ______
              Подводка: ______
              Итог: ______

[__:__]  СВОБОДНОЕ ВРЕМЯ / ПЕРЕРЫВ                РЕЗЕРВ: ___ мин
       [__:__] Что происходит: [еда / фотосессия / общение]
       [__:__] Моя задача в это время: [обход столов / фото / отдых]
```

### Блок 5. Акцентный блок

Главный эмоциональный момент вечера. Здесь текст пишется дословно.

```
[__:__]  [НАЗВАНИЕ АКЦЕНТНОГО БЛОКА]            резерв: ___ мин

       [__:__] Подводка (20–30 сек): ______
       [ТЕХНИКА] Действие: [выход / музыка / свет]
       [__:__] Текст блока:
              [ДОСЛОВНО] ______
              [ДОСЛОВНО] ______
       [ПАУЗА 2 сек] Перед ключевой фразой
       [ДОСЛОВНО] Ключевая фраза: ______
       [__:__] Возврат к залу: ______
```

### Блок 6. Финал (3–10 минут)

Мягкое приземление (урок 2.5): сначала эмоция, потом тост, потом прощание.

```
[__:__]  ФИНАЛ

       [__:__] Сбор зала, музыка: [трек]
       [__:__] Подводка к финалу: ______
       [ДОСЛОВНО] Финальные слова: ______
       [__:__] Последний тост: [за что], [кто поднимает бокал]
       [ДОСЛОВНО] Тост (2–3 мин): ______
       [__:__] Прощание: ______
       [__:__] Что после финала: [музыка, свобод, трансфер]
```

## Аварийные точки

Заполните до мероприятия — это ваш запасной план (урок 3.5, 4.4).

```
ТЕХНИКА НЕ РАБОТАЕТ: ______ (что делаю вместо блока)
ОПОЗДАЛИ ГОСТИ: ______ (жду или начинаю)
ГЕРОЙ НЕ ПРИШЁЛ: ______
ОТМЕНИЛИ ТАНЕЦ / ЦЕРЕМОНИЮ: ______
ПЬЯНЫЙ ГОСТЬ: ______ (имя [кто из семьи поможет])
РЕБЁНОК ПЛАЧЕТ: ______
ЗАЛ НЕ СЛУШАЕТ, ТИШИНА: ______
НУЖНО ЗАЛЯТЬ НА 10 МИНУТ: ______
СВЕТ ПОГАС: ______
ПОГОДА (уличное): ______
```

## Что выучить наизусть

```
1. Полные имена героев: ______
2. Имена родителей / ключевых гостей: ______
3. Имена спикеров: ______
4. Ключевые цифры (даты, стаж, количество гостей): ______
5. Названия организаций: ______
6. Названия номинаций (корпоратив): ______
7. Порядок выступлений: ______
```

## Проверка перед мероприятием

- [ ] Все блоки 0–6 заполнены, ни одного пустого места
- [ ] Все имена выписаны и проверены с организатором
- [ ] Аварийные точки заполнены
- [ ] Ключевые тексты выучены наизусть (проверить через день)
- [ ] Тайминг сходится с минутной сеткой
- [ ] Есть резерв 10% в сетке
- [ ] Сценарий есть на телефоне и в облаке
- [ ] Карточки написаны от руки и лежат в папке
