# Сайт диджея — материалы для сборки

Сайт продажи курса «Диджеинг с нуля». Один лендинг, который продаёт курс, и служебные страницы рядом с ним.

Платформа: **Tilda** (Zero Block + стандартные блоки), домен свой, оплата через встроенный приём платежей Tilda или через свою платёжную ссылку.

## Что здесь лежит

| Файл | Что это |
|---|---|
| `01_Структура и тексты.md` | Все тексты по блокам главной страницы. Копировать в Tilda как есть |
| `02_Сборка в Tilda.md` | Пошаговая инструкция: тариф, домен, блоки, шрифты, цвета, публикация, аналитика |
| `03_Формы, заявки, CRM.md` | Формы, автоответ, куда ведут заявки, таблица учёта, работа с заявкой в первые 24 часа |
| `04_Дизайн, SEO, домен.md` | Палитра, шрифты, как показать технику без стоковых фото, домен, мета-теги, FAQ |
| `05_Страница курса — тексты.md` | Тексты страницы продажи курса: программа, тарифы, гарантия, возражения |

**Обрати внимание на нумерацию:** файл про сборку здесь второй, а про тексты страницы курса — пятый. В папке «Сайт ведущего» порядок другой. Не перепутай, они закрывают разные задачи: `01` и `05` — тексты, `02`, `03`, `04` — настройка.

## Порядок работы

1. Прочитать `01` и `05` — это готовые тексты, вставляются без правок.
2. Заменить все `[ПЛЕЙСХОЛДЕРЫ]` на свои данные.
3. Собрать главную по `02`.
4. Настроить по `04` (цвета, шрифты, домен, мета-теги).
5. Подключить приём заявок и оплату по `03`.
6. Пройти чек-лист публикации в конце `02`.
7. Проверить заявку вручную с телефона и с незалогиненного окна.

Сначала тексты, потом сборка. Не наоборот: если собирать блоки по одной и писать текст по ходу, структура расползётся и два блока будут говорить одно и то же разными словами.

## Плейсхолдеры — заменить все

| Плейсхолдер | Что вписать | Где |
|---|---|---|
| `[ИМЯ]` | Имя и фамилия | Заголовки, подписи под фото |
| `[ГОРОД]` | Город, откуда вы работаете и где ищете первые выступления | Обложка, подвал, SEO |
| `[ТЕЛЕГРАМ]` | Ссылка на Telegram | Кнопки, подвал, автоответ |
| `[ПОЧТА]` | Почта для заявок | Подвал, уведомления Tilda |
| `[ЦЕНА_КУРСА]` | Твоя цена за курс | Тарифы, кнопки |
| `[ЦЕНА_ТАРИФА_1]`…`[ЦЕНА_ТАРИФА_3]` | Цены тарифов, если их несколько | Блок тарифов |
| `[URL_КУРСА]` | Адрес страницы курса | Кнопки на главной |
| `[ДАТА_ПОТОКА]` | Дата или месяц ближайшего набора | Обложка, тарифы |
| `[ЧИСЛО_МЕСТ]` | Сколько мест в наборе | Блок тарифов |
| `[ОПЛАТА_ССЫЛКА]` | Ссылка на оплату, если ведёшь через свой сервис | Кнопки |

**Про цены.** В текстах стоят плейсхолдеры вида `9 900 ₽` с пометкой «подставить свою цену». Методика расчёта — в конце файла `05_Страница курса — тексты.md`. Не оставляй цифру, не проверив счёт.

## О чём сайт

Позиционирование, которое заложено в текстах: **не «я учуть играть музыку», а «ты сведёшь два трека вручную и сыграешь 60 минут перед людьми»**. Диджеинг — это ремесло с измеримым навыком, и именно это отличает страницу от тысяч «курсов заработка на музыке».

Что продаём по факту:

- **Результат:** первое выступление в горизонте 8–12 недель. Не «доход», не «свобода» — конкретная дата площадки.
- **Проверяемость:** 35 уроков, 6 модулей, домашние задания с критериями, чек-лист выпускника из 8 пунктов.
- **Честность цены:** техника покупается в модуле 2, до этого курс работает с телефоном и любыми наушниками. Это снимает главный барьер «у меня нет денег на старте».

Три страницы:

- Главная — позиционирование, для кого, программа, результат, форматы работы, заявка
- Курс — продажа курса как продукта: программа по модулям, тарифы, гарантия возврата, 8 возражений, кейс ученика
- Политика конфиденциальности — нужна для рекламы, для тарифов и для формы с данными

## Решения, которые уже приняты

| Вопрос | Решение | Почему |
|---|---|---|
| Платформа | Tilda | Сборка без кода, оплата из коробки, аналитика в одном месте |
| Тариф Tilda | Personal или Business | На бесплатном нельзя подключить свой домен и убрать служебные элементы |
| Палитра | Тёмная база + кислотный акцент | Аудитория пришла из соцсетей, тёмная база читается как «своя среда» |
| Шрифты | Один моноширинный для служебных блоков + гротеск для текста | Ассоциация с софтом и сетапом, а не с «музыкальной школой» |
| Фото | Свои: руки на контроллере, сетап, зал | Стоковые фото диджеев мгновенно убивают доверие |
| Структура | Одна длинная главная, без отдельного блога на старте | Задача — первые продажи, а не трафик |
| Оплата | Встроенная Tilda на старте, своя платёжка после 10 продаж | Автовыдача доступа экономит нервы |
| Заявки | Telegram + почта + таблица, три канала | Заявка не должна потеряться, если закрылся мессенджер |
| Гарантия | Возврат за первую неделю, без обещаний дохода | Возврат — это про деньги и доверие, доход не гарантируем |
| Обещание дохода | Не используется нигде | Прямое «не гарантирую» повышает конверсию сильнее обещания |

## Готовый текст о результате

Формулировка, которая должна работать везде одинаково — на обложке, в тарифах, в подвале, в сообщениях:

```
6 недель. 35 уроков. 5–7 часов в неделю. Первое выступление в горизонте 8–12 недель — это цель курса, а не пожелание.
```

## Чего не делать с этими файлами

- Не сокращать тексты «под короткий лендинг». Длинная страница с конкретикой конвертирует лучше, чем пять блоков и кнопка.
- Не переписывать формулировки про доход в сторону обещаний. Один обещатель дохода обнуляет всю страницу для внимательного читателя.
- Не публиковать до тех пор, пока не пройден чек-лист в конце `02`. Половина проблем видна только с телефона и из незалогиненного окна.
- Не выдумывать отзывы и кейсы. Если учеников ещё нет — вместо отзывов ставится блок «что будет на выходе», и это честнее.
- Не менять числа (6 недель, 35 уроков, 5–7 часов) ради красоты формулировки. Цифры — это доказательство, а не украшение.
