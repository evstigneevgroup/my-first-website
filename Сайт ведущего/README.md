# Сайт ведущего — материалы для сборки

Личный сайт для работы с заказами на ведение мероприятий + страница продажи курса.

## Что здесь лежит

| Файл | Что это |
|---|---|
| `01_Структура и тексты.md` | Все тексты по блокам главной страницы. Копировать в Tilda как есть |
| `02_Страница курса — тексты.md` | Тексты страницы продажи курса |
| `03_Сборка в Tilda.md` | Пошаговая инструкция: создать проект, накидать блоки, настроить |
| `04_Дизайн, SEO, домен.md` | Цвета, шрифты, мета-теги, домен, аналитика, мелочи, которые забывают |
| `05_Формы, заявки, CRM.md` | Как принимать заявки и куда их складывать |

## Порядок работы

1. Прочитать `01` и `02` — это готовые тексты.
2. Заменить все `[ПЛЕЙСХОЛДЕРЫ]` на свои данные.
3. Собрать по `03`.
4. Настроить по `04`.
5. Подключить приём заявок по `05`.
6. Пройти чек-лист публикации в конце `03`.

## Плейсхолдеры — заменить все

| Плейсхолдер | Что вписать | Где |
|---|---|---|
| `[ИМЯ]` | Имя и фамилия | Заголовки, подписи к фото |
| `[ГОРОД]` | Город и регион работы | Обложка, подвал, SEO |
| `[ТЕЛЕГРАМ]` | Ссылка на Telegram | Кнопки, подвал |
| `[ВАТСАП]` | Ссылка на WhatsApp | Кнопки |
| `[ТЕЛЕФОН]` | Телефон (по желанию) | Подвал |
| `[ПОЧТА]` | Почта для заявок | Подвал, форма |
| `[ЦЕНА]` | Твоя цена за вечер | Блок цен |
| `[СТАТЬЯ_1]`…`[СТАТЬЯ_3]` | Слоты под кейсы | Блок кейсов |
| `[ОТЗЫВ_1]`…`[ОТЗЫВ_4]` | Реальные отзывы клиентов | Блок отзывов |
| `[URL_КУРСА]` | Куда ведёт кнопка «Купить курс» | Если курс на отдельной странице |

## О чём сайт

Позиционирование, которое заложено в текстах: **не «я читаю сценарий», а «я держу зал и веду людей по плану»**. Это отличает от 90% конкурентов, у которых в описании «сценарий, программа, шоу».

Три страницы:
- Главная — кто я, что делаю, кейсы, отзывы, цены, заявка
- Курс — продажа курса «Ведущий мероприятий с нуля»
- Политика конфиденциальности — нужна для рекламы и рекламы в тарифах
