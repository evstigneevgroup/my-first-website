# Формы, заявки, CRM

Самое важное: **заявка должна попасть туда, где ты её увидишь за 10 минут, а не через три дня.** Всё остальное вторично.

---

## Вариант 1. Telegram — проще всего (рекомендую на старте)

Сообщение с заявкой падает тебе в чат. Ответил — заявка закрыта.

### Настройка

1. Создать бота через [@BotFather](https://t.me/botfather) → `/newbot` → дать имя → получить **токен**.
2. Узнать свой **Chat ID**: написать боту любое сообщение, открыть `https://api.telegram.org/bot<ТОКЕН>/getUpdates`, найти `"chat":{"id":...}`.
3. В Tilda: блок T-Forms → **Настройки формы** → **Отправка** → **Подключить сервис** → **Telegram**.
4. Вписать токен и Chat ID.

### Проверка

Отправить тестовую заявку с сайта. Если бот молчит — проверить Chat ID (частая ошибка: id канала вместо id пользователя; канал начинается с `-100`).

**Плюс:** заявка приходит мгновенно, отвечать можно прямо из Telegram.
**Минус:** если Telegram-аккаунт закрыт или ты в отпуске — заявки пропадут. Поэтому вариант 2 тоже настроить.

## Вариант 2. Почта — обязательный дублёр

1. В настройках T-Forms → **Отправка** → включить **Email**.
2. Вписать свой адрес `[ПОЧТА]`.
3. В **Уведомлениях** → настроить шаблон письма: тема, имя клиента, все поля заявки.

**Правила, чтобы почта не потерялась:**
- Завести отдельный адрес для заявок: `[ПОЧТА]`, не личный. Иначе заявки смешаются с рассылками и письмами
- Уведомление на **другой** адрес, чем тот, куда ты читаешь сам — чтобы не пропустить из-за фильтра
- В письме: имя, формат, дата, контакт клиента — всё, что нужно для ответа без переписки

## Вариант 3. CRM

Если работаешь регулярно и заявок больше 5 в месяц — подключить CRM.

**Tilda поддерживает из коробки:**

| CRM | Что даёт |
|---|---|
| amoCRM | Воронка заявок, задачи менеджеру |
| Bitrix24 | Полная CRM, если нужна |
| Google Sheets | Таблица заявок, бесплатно |
| Mailchimp / SendPulse | Рассылка по базе клиентов |

**Как подключить:** Настройки формы → Отправка → Подключить сервис → выбрать CRM → авторизовать.

**Зачем CRM, если есть Telegram:** заявка из Telegram живёт в чате, из CRM — в воронке. Разница: через месяц ты видишь, что 6 заявок в сумме принесли 1 заказ, а 3 были не по адресу. Из этого рождаются выводы, из которых растут деньги.

## Вариант 4. Приём оплаты за курс

### Встроенный платёж Tilda

1. Блок → **Продажа и оплата** (или **T-Store**).
2. Загрузить файл (видеоуроки, PDF-шпаргалки) или указать ссылку на курс.
3. Настройки → **Оплата** → подключить платёжную систему.

**Минус:** комиссия Tilda, и деньги приходят на аккаунт Tilda, дальше вывод вручную.

### Своя платёжная ссылка

Если уже есть ЮKassa / Тинькофф / Stripe:
1. Создать платёжную ссылку на сумму `[ЦЕНА_КУРСА]`.
2. В кнопке «Записаться на курс» указать эту ссылку.
3. После оплаты вручную отправить доступ.

**Плюс:** меньше комиссии, доступ к деньгам сразу.
**Минус:** ручная работа, отзывы, если забудешь выдать доступ.

> Что выбрать: на старте — **встроенный платёж Tilda**, потому что автоматическая выдача доступа экономит нервы. Свою платёжку подключать, когда пойдут первые 10 продаж.

## Куда вести заявку в работу

Простая таблица, чтобы не терять:

| Поле | Значение |
|---|---|
| Дата заявки | |
| Имя | |
| Контакт | |
| Формат | свадьба / юбилей / корпоратив |
| Дата мероприятия | |
| Бюджет | |
| Статус | новая → в работе → отказ / договор / проведено |
| Итог | состоялось / перенос / отмена |

**Правило «отклик в течение дня»:**
- Ответ в первый час конвертирует в 4 раза лучше, чем ответ через сутки
- Фраза первого ответа: задай 2–3 вопроса (дата, место, формат), не отправляй прайс
- Прайс — после того, как понял задачу. Иначе это разговор ни о чём

---

## Что писать в первом ответе

```
[ИМЯ], привет! Спасибо за заявку.

Чтобы прикинуть стоимость, нужно три вещи:
1. Дата и примерное время начала
2. Место (город, площадка)
3. Примерно сколько гостей и какой формат

Если удобнее — на 10 минут созвонимся, мне так быстрее понять задачу.
```

Коротко, конкретно, с одним предложением про звонок. Не «пришлите подробности вашего мероприятия» — это отправляет человека заполнять анкету, и половина заявок умирает здесь.

## Безопасность данных

Обязательно, если форма собирает имена и телефоны:

- [ ] Страница политики конфиденциальности опубликована и заполнена
- [ ] Чекбокс согласия в форме включён
- [ ] В политике указано, какие данные собираются и сколько хранятся
- [ ] Указано, с кем данные делятся (платёжная система, хостинг, CRM, Telegram)
- [ ] Указан способ удалить данные: `[ПОЧТА]`

При проверке (особенно если пойдут жалобы или реклама) отсутствие политики — самая частая причина проблем. Написать честную короткую политику лучше, чем не написать никакую.
