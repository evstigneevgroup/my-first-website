# Структура и тексты главной страницы

11 блоков сверху вниз. Каждый блок: сначала тексты, потом пометки что вставлять.

**Смысл страницы:** за 40 секунд человек должен понять — ты ведущий, ты умеешь, ты свободен. И нажать «Написать».

---

## Блок 1. Обложка (первый экран)

**Тип блока в Tilda:** Обложка (Cover) или Нулевой блок. Для обложки проще Обложка.

**Фон:** видео или фото с микрофоном в руке, замутнённое, чтобы читался текст.

**Заголовок:**
```
[ИМЯ] — ведущий мероприятий в [ГОРОД]
```

**Подзаголовок:**
```
Свадьбы, юбилеи, корпоративы, выпускные. Держу зал и веду вечер по плану, который сначала пишется, а потом импровизируется.
```

**Кнопка одна (главная):**
```
Обсудить мероприятие
```

**Мелкий текст под кнопкой:**
```
Свободен на [ДАТА/ПЕРИОД]. Выезд по России, за границу — по договорённости.
```

**Пометки:**
- Заголовок до 70 символов, иначе ломается на мобильном
- Кнопка ведёт на форму заявки — якорь `#zayavka`
- Мелкий текст — приглушённый серый, размер меньше основного
- Мобильная версия проверяется отдельно: обложка не должна занимать больше одного экрана

## Блок 2. Кто я

**Тип блока:** Текст + фото. Две колонки: слева фото в полный рост с микрофоном, справа текст.

**Заголовок:**
```
Ведущий — не тот, кто читает. Тот, кто держит зал.
```

**Текст:**
```
Меня зовут [ИМЯ]. Я веду мероприятия в [ГОРОД] и области уже [СКОЛЬКО_ЛЕТ] лет.

Моя работа начинается не с микрофона. Сценарий мероприятия я пишу заранее: собираю информацию о людях, о поводе, о том, что должно произойти к концу вечера. На самом событии половина текста уходит в запас — потому что зал всегда живой, и его нельзя заранее положить на рельсы.

Что делаю по факту:
- держу темп вечера, чтобы никто не устал и никто не потерялся
- переключаюсь между церемонией, конкурсом, музыкой и разговором без «пауз»
- читаю зал и подстраиваю речь под людей, а не под текст
- закрываю неожиданное: опоздание, отмену, конфликт, сломанный микрофон

Формат, в котором я работаю лучше всего — [СВАДЕБЫ / КОРПОРАТИВЫ / ЮБИЛЕИ]: [одно предложение о том, что именно ты делаешь в этом формате].
```

**Пометки:**
- Фото должно быть живое: микрофон, зал, ты в кадре. Не студийный портрет
- Список «что делаю» — маркированный список, без буллетов-капель
- `[СКОЛЬКО_ЛЕТ]` и `[ФОРМАТ]` заполнить обязательно: пустое место на главной выглядит как «сайт-визитка 2012 года»

## Блок 3. Форматы

**Тип блока:** 4 карточки в ряд (или 2×2 на мобильном).

**Заголовок блока:**
```
Форматы
```

**Подзаголовок блока:**
```
Один и тот же ведущий, разная работа. Ниже — что я делаю в каждом формате.
```

**Карточка 1:**
```
Свадьбы
Открытие, регистрация, первый танец, тосты, финал. Сценарий пишется с парой и организатором, ямы и шок-контент не в моей части.
```
**Карточка 2:**
```
Юбилеи и дни рождения
Главный вечер без сюрпризов от родственников. Держу темп, чтобы программа не растянулась и не рассыпалась.
```
**Карточка 3:**
```
Корпоративы
Новый год, юбилей компании, тимбилдинг. Сценарий под задачу: награждение, запуск продукта, корпоративная игра.
```
**Карточка 4:**
```
Публичные события
Конференции, презентации, форумы. Ведение с микрофоном на сцене, подбор слов для непрофессиональной аудитории.
```

**Пометки:**
- Иконка в каждой карточке — одна и та же набор, не разные стили
- Названия карточек — заголовком карточки, текст обычным

## Блок 4. Как проходит работа

**Тип блока:** Блок с шагами (Steps / Steps list). 5 шагов по вертикали.

**Заголовок блока:**
```
Как проходит работа
```

**Шаг 1 — Заголовок:**
```
1. Знакомство
```
**Шаг 1 — Текст:**
```
15–20 минут созвона или встречи. Обсуждаем повод, дату, место, состав гостей и что для вас важно.
```

**Шаг 2 — Заголовок:**
```
2. Сценарий
```
**Шаг 2 — Текст:**
```
Пишу под ваше мероприятие: спикеров, конкурсы, тосты, музыку, моменты. Не шаблон из интернета. Вы читаете текст и правите — ваш голос должен быть в сценарии.
```

**Шаг 3 — Заголовок:**
```
3. Брифа и согласование
```
**Шаг 3 — Текст:**
```
Финальная версия с таймингом: что в какой минуте, где пауза, где музыка. Вы согласовываете — дальше я работаю по нему.
```

**Шаг 4 — Заголовок:**
```
4. Площадка
```
**Шаг 4 — Текст:**
```
Приезжаю за 1,5–2 часа. Проверяю звук, микрофоны, точки выхода и входа сцены. Если техника площадки не тянет — решаем на месте.
```

**Шаг 5 — Заголовок:**
```
5. Мероприятие
```
**Шаг 5 — Текст:**
```
Веду вечер по сценарию, остальное — по залу. После — отдаю вам сценарий и тайминг, если заказывали.
```

**Пометки:**
- Этот блок снимает половину тревоги: человек видит, что будет дальше
- Если сложится — добавь в каждый шаг срок («сценарий за 7 дней», «брифа за 2 дня»)

## Блок 5. Кейсы

**Тип блока:** Галерея из 3 карточек или слайдер. Каждая карточка: фото/обложка + текст + результат.

**Заголовок блока:**
```
Кейсы
```

**Кейс 1:**
```
Свадьба, 80 гостей, [ГОРОД]
Формат: зал + мантра. Задача: без «микрофонных» пауз и без чтения с листа.
Что сделал: сценарий на 8 блоков с таймингом, импровизация вместо двух тостов, конкурс вместо второго танца.
Результат: вечер отыграл по времени, пара уехала без правок.
```
**Кейс 2:**
```
Корпоратив на 200 человек, новогодний
Формат: сцена. Задача: награждение без «встали-похлопали-сели».
Что сделал: перестроил церемонию в три коротких блока с игровыми паузами, поднял вовлечённость зала.
Результат: церемония прошла на 6 минут короче плана, зал не ушёл в телефоны.
```
**Кейс 3:**
```
Юбилей, 30 лет, загородный дом
Формат: без сцены. Задача: тёплая программа без пафоса.
Что сделал: чередование официальных и шуточных блоков, тосты от гостей встроил в тайминг, а не в конец.
Результат: программа не растянулась, именинник не устал от сцены до вина.
```

**Пометки:**
- Каждый кейс должен содержать цифру или конкретный результат. «Было весело» не считается
- Если кейсов пока нет — замени блок на «как я работаю» с фотографиями с площадок. Лучше без кейсов, чем с выдуманными
- Фото реальных гостей — только с разрешения. Без него оставь кадры со сцены, пустые залы, ваш силуэт

## Блок 6. Отзывы

**Тип блока:** Слайдер отзывов или 4 карточки.

**Заголовок блока:**
```
Отзывы
```

**Отзыв 1:**
```
«Вечер вёл так, что мы вообще не заметили, кто это делает. Все были заняты делом, а не ведущим.»
— Имя, фамилия, формат
```
**Отзыв 2:**
```
«Сценарий пришёл за неделю, мы его переписали под себя — он реально был рабочий, а не из интернета.»
— Имя, фамилия, формат
```
**Отзыв 3:**
```
«Самое ценное — он не читал. Всё равно всё прошло по плану.»
— Имя, фамилия, формат
```
**Отзыв 4:**
```
«Отдельная боль была: у нас сломался микрофон уже во время мероприятия. Всё продолжилось без паузы.»
— Имя, фамилия, формат
```

**Пометки:**
- Настоящая боль: отзывы без «формата» читаются как спам
- Ссылка на оригинал отзыва (в мессенджере/на карте) сильно повышает доверие
- Если отзывов пока нет — замени блок на фото-галерею с площадок. Не выдумывай, это разрушает доверие быстрее, чем отсутствие отзывов

## Блок 7. Цены

**Тип блока:** Блок тарифов или простые цены текстом.

**Заголовок блока:**
```
Сколько стоит
```

**Тариф 1:**
```
Свадьба
от [ЦЕНА_1] ₽
Полный вечер, сценарий под пару, тайминг, встреча на площадке.
```
**Тариф 2:**
```
Юбилей / день рождения
от [ЦЕНА_2] ₽
Программа, сценарий, ведение.
```
**Тариф 3:**
```
Корпоратив
от [ЦЕНА_3] ₽
Сценарий под задачу, работа со сценой и звуком площадки.
```

**Текст под тарифами:**
```
В стоимость не входит аренда площадки, звук, видео и удержание гостей. Оплата — по договору, по предоплате 50%, остаток в день мероприятия.

Точная цена зависит от длительности, количества гостей и того, есть ли сцена. На созвоне считаю за 10 минут.
```

**Пометки:**
- Цены в блок тарифов нужны: «цена по запросу» отсекает половину обращений, «от X ₽» не отсекает
- «от» защищает тебя: длительность варьируется
- Опрос: минимальная сумма, до которой ты реально опускаешься, должна быть указана. Мелкий текст под тарифом — обязательно

## Блок 8. Курс

**Тип блока:** Обложка-карточка на полполосы. Фото с микрофоном или разворот книги.

**Заголовок блока:**
```
Хочешь вести сам
```

**Текст блока:**
```
Курс «Ведущий мероприятий с нуля» — 6 недель, 6 модулей, от 5 до 7 часов в неделю. Голос и речь, сценарий с таймингом, звук на площадке, импровизация, четыре готовых сценария и профессия: цена, договор, первые заказы.

Результат — первое проведённое мероприятие и система, по которой можно брать следующие.
```

**Кнопка блока:**
```
Программа и условия
```

**Мелкий текст под кнопкой:**
```
Без домашних заданий модуль не закрывается. Это не лекция, а практика с обратной связью.
```

**Пометки:**
- Этот блок ведёт на отдельную страницу курса (см. `02_Страница курса — тексты.md`)
- Не продавай «доход и свободу». Продавай «первое мероприятие и понятную систему» — это правда и это сильно
- «Без домашних заданий не закрывается» снимает ожидание «посмотрел и всё»

## Блок 9. Как начать

**Тип блока:** Форма заявки (Опросы и формы → T-Forms).

**Заголовок блока:**
```
Как начать
```

**Подзаголовок блока:**
```
Напишите, что за мероприятие и когда. Отвечаю в течение дня.
```

**Поля формы:**

| Поле | Тип | Обязательное | Подсказка |
|---|---|---|---|
| Имя | Текст | Да | Как к вам обращаться |
| Формат и дата | Текст | Да | Свадьба 12.08, юбилей 20.09 |
| Телефон или Telegram | Текст | Да | Номер с кодом или ссылка на профиль |
| Город мероприятия | Текст | Нет | |
| Что важно на вашем вечере | Многострочное поле | Нет | Пара предложений |

**Кнопка формы:**
```
Отправить
```

**Мелкий текст под кнопкой (обязательно, не удалять):**
```
Нажимая «Отправить», вы соглашаетесь с [Политикой конфиденциальности].
```

**Пометки:**
- Больше пяти полей не нужно. Каждое лишнее поле снижает число отправок
- Подписи к полям — в человек читаемые («Ваше имя»), не технические («Name»)
- Якорь `#zayavka` — на этот блок ведут все кнопки «Обсудить» и «Написать»
- Подключение отправки — по инструкции `05_Формы, заявки, CRM.md`

## Блок 10. Вопросы

**Тип блока:** Блок «Вопрос-ответ» (FAQ). Аккордеон.

**Заголовок блока:**
```
Частые вопросы
```

**Вопрос-ответ 1:**
```
За сколько времени нужно подтвердить дату?
За 2–3 недели — спокойно, сценарий успевает пройти ваши правки. За неделю — тоже беру, но сценарий будет плотнее и без второго круга согласования.
```

**Вопрос-ответ 2:**
```
Что нужно от меня подготовить?
Список гостей, площадку и её техника, имена людей, которых надо представить, музыкальный плейлист. Всё остальное я спрошу сам в анкете клиента.
```

**Вопрос-ответ 3:**
```
Можно ли посмотреть, как вы ведёте?
Да, на каждом мероприятии я веду фото- и видеосъёмку, отдельно готови нарезку. Ссылку пришлю после встречи.
```

**Вопрос-ответ 4:**
```
Мы сами пишем сценарий — вы всё равно нужны?
Как ведущий, да: подскажу, что убрать, где пауза, где нужно взять зал. Часто получается, что готовить сценарий не нужно — достаточно грамотно им управлять.
```

**Вопрос-ответ 5:**
```
Какие инструменты нужны?
Бесплатных хватает. Плейлисты и подборки, таймер, диктофон для репетиции. Покупать микрофон на старте не обязательно — на площадках обычно есть своя техника.
```

**Вопрос-ответ 6:**
```
Вы работаете за границей?
Да, если мероприятие в стране, где я могу приехать. Пишите заранее — логистика занимает время.
```

**Пометки:**
- Ответы с конкретикой («за 2–3 недели») читаются увереннее, чем ответы в общих словах
- Вопросы про «свои инструменты» и «свой сценарий» снимают возражение «я справлюсь сам»

## Блок 11. Подвал

**Тип блока:** Подвал (Footer) + Т-контакты.

**Подзаголовок блока:**
```
Свободен на [ДАТА/ПЕРИОД]. Выезд по России и за границу.
```

**Контакты:**
```
[ИМЯ] — ведущий мероприятий в [ГОРОД]
Telegram: [ТЕЛЕГРАМ]
WhatsApp: [ВАТСАП]
Телефон: [ТЕЛЕФОН]
Почта: [ПОЧТА]
```

**Ссылки в подвале:**
```
Кейсы · Отзывы · Курс · Политика конфиденциальности
```

**Мелкий текст:**
```
© [ГОД] [ИМЯ]. Все права защищены. Хостинг — Tilda.
```

**Пометки:**
- Мессенджеры важнее телефона: на свадьбе и в зале телефон в кармане. Пиши «Напишите в Telegram» основной кнопкой
- «Все права защичены» в подвале — не имеет силы и стоит места; можно убрать, но тогда добавь год к названию. Одно из двух
- Политика конфиденциальности — обязательна, если форма с данными и/или платёж

## Порядок блоков — почему такой

| # | Блок | Зачем |
|---|---|---|
| 1 | Обложка | Имя, лицо, форматы, действие |
| 2 | Кто я | Почему можно доверять |
| 3 | Форматы | Совпадение с задачей посетителя |
| 4 | Как проходит работа | Снять тревогу |
| 5 | Кейсы | Доказательства |
| 6 | Отзывы | Социальное доказательство |
| 7 | Цены | Фильтр: остаются те, у кого есть деньги |
| 8 | Курс | Второй продукт, другой чек |
| 9 | Как начать | Заявка |
| 10 | Вопросы | Снять последние возражения |
| 11 | Подвал | Контакты и поводное действие |

**Что можно убрать без потерь:** блок 10 (вопросы) и блок 2 (кто я), если обложка уже несёт имя и фото. **Что нельзя убирать:** цены, форму заявки, кейсы или отзывы — то есть доказательства и способ написать.
