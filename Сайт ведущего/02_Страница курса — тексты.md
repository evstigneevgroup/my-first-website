# Страница курса — тексты

Отдельная страница: `Курс`. Ссылка из блока 8 главной и из подвала.

**Логика страницы:** человеку уже интересно (он пришёл с главной), поэтому здесь меньше «кто я» и больше «что внутри, сколько это, как купить».

---

## Блок 1. Обложка курса

**Заголовок:**
```
Курс «Ведущий мероприятий с нуля»
```

**Подзаголовок:**
```
6 недель. 6 модулей. 5–7 часов в неделю. Первое проведённое мероприятие и система, по которой можно брать следующие.
```

**Кнопка:**
```
Что внутри курса
```

**Мелкий текст:**
```
Для тех, кто никогда не вёл. Опыт, техника и деньги на старте не нужны.
```

---

## Блок 2. Для кого

**Заголовок блока:**
```
Кому это нужно
```

**Текст:**
```
Курс для тех, кто хочет вести, но боится первой ошибки. Не для тех, кто уже ведёт и хочет больше форматов.

Подойдёт, если вы:
- никогда не держали микрофон или работали только в узком кругу
- боитесь, что начнём импровизировать и поплывём
- понимаете, что нужен сценарий, но не знаете, как его писать
- хотите зарабатывать, а не собирать одно мероприятие «для друзей»

Не подойдёт, если вы ищете доход за неделю без подготовки и без практики.
```

**Пометка:** строка «не подойдёт» делает текст честнее и повышает доверие к остальному. Не убирать.

## Блок 3. Программа по модулям

**Тип блока:** Блок с шагами или аккордеон. 6 шагов, каждый с названием модуля, темой и результатом.

**Заголовок блока:**
```
Программа
```

**Модуль 1 — Заголовок:**
```
Модуль 1. Голос и речь
```
**Модуль 1 — Текст:**
```
Микрофон и ухо слушателя, артикуляция, темп и паузы, слова-паразиты, интонация, стоп-слово.
Результат: чистая речь с микрофона без «эканий» и заминок.
```

**Модуль 2 — Заголовок:**
```
Модуль 2. Сценарий и тайминг
```
**Модуль 2 — Текст:**
```
Анатомия сценария, минутная сетка, открытие, блоковые речи, финал, что писать, а что не писать.
Результат: рабочий сценарий на 3 часа с минутной сеткой.
```

**Модуль 3 — Заголовок:**
```
Модуль 3. Техника и звук
```
**Модуль 3 — Текст:**
```
Минимальный комплект, подключение, звук в помещении, источники проблем, резервный план.
Результат: своя «аппаратурка» и звук на площадке под контролем.
```

**Модуль 4 — Заголовок:**
```
Модуль 4. Импровизация и зал
```
**Модуль 4 — Текст:**
```
Удержание зала, импровизация на опорах, неохотные и бойкие, конфликты, личное присутствие, спасательные фразы.
Результат: ответ на любой непредвиденный момент без паники.
```

**Модуль 5 — Заголовок:**
```
Модуль 5. Форматы
```
**Модуль 5 — Текст:**
```
Свадьба, корпоратив, юбилей, публичное событие. Четыре готовых сценария под четыре типовые задачи.
Результат: сценарий под конкретный формат, а не общие слова.
```

**Модуль 6 — Заголовок:**
```
Модуль 6. Профессия
```
**Модуль 6 — Текст:**
```
Первый заказ, цена, договор, поиск клиентов, отзывы, повторные клиенты, рост.
Результат: первые деньги за ведение и понятный путь до следующих заказов.
```

**Мелкий текст после программы:**
```
Модули проходятся по порядку. Модуль 2 бессмысленен без первого.
```

## Блок 4. Как проходит обучение

**Заголовок блока:**
```
Как проходит обучение
```

**Текст:**
```
Материалы открыты сразу, но идти нужно по порядку: каждый модуль опирается на предыдущий.

Каждый урок — теория, практика и домашнее задание с критериями проверки. Вы делаете ДЗ, сдаёте его в аудио или видео, получаете обратную связь. Включая неудачные дубли — так быстрее видно, что чинить.

Критерий в ДЗ есть всегда. Это значит, что до отправки можно проверить себя самому и понять, готовы ли вы.

Время: 5–7 часов в неделю. Шесть недель.
```

**Пометка:** фраза «включая неудачные дубли» объясняет, почему сдавать страшно не стоит. Это снимает главный барьер у новичков.

## Блок 5. Что входит

**Тип блока:** Два столбца со списком. Слева «Входит», справа «Не входит».

**Заголовок блока:**
```
Что входит
```

**Входит:**
```
- 6 модулей, 28 уроков
- Шаблоны: сценарий с минутной сеткой, анкета клиента, договор
- Четыре готовых сценария: свадьба, корпоратив, юбилей, публичное событие
- Разборы реальных ситуаций и типичных ошибок
- Домашние задания с критериями проверки
- Обратная связь по вашим ДЗ
- Доступ к материалам навсегда
```

**Не входит:**
```
- Личные встречи и «ведение за руку»
- Разбор вашей записи один на один в прямом эфире
- Готовый сценарий под ваше мероприятие
- Гарантия заказа
```

**Пометки:** «не входит» повышает доверие и отсекает тех, кто не совпадёт по ожиданиям. Не выглядит как «мы ничего не даём», если рядом сильный список «входит».

## Блок 6. Формат

**Заголовок блока:**
```
Формат
```

**Текст:**
```
Самостоятельная работа с обратной связью. Уроки в текстовом виде, шаблоны и сценарии — файлами, сразу и навсегда.

Вы сами выбираете темп. Единственное, что требуется, — сдавать домашние задания. Без них модуль не закрывается: теория без практики в ведении не работает.

Если вы проходите курс с наставником, сдавайте ДЗ целиком, включая неудачные дубли.
```

## Блок 7. Цена и условия

**Тип блока:** Тарифы или один тариф с ценой.

**Заголовок блока:**
```
Условия
```

**Цена:**
```
[ЦЕНА_КУРСА] ₽
```

**Старая цена (если есть скидка):**
```
было [ЦЕНА_КУРСА_СТАРАЯ] ₽
```

**Текст:**
```
Один платёж. Доступ сразу после оплаты. Если прошли неделю и понимаете, что не ваше — вернём полную стоимость.
```

**Кнопка:**
```
Записаться на курс
```

**Мелкий текст под кнопкой:**
```
Оплата картой или по счёту. Для организаций — счёт с закрывающими документами.
```

**Пометки:**
- Гарантия возврата — сильный аргумент, но давай только то, что готов выполнить. Настоящая гарантия снимает возражение сильнее любого текста
- «Старая цена» — только с реальной историей скидки. Фальшивая скидка — это не маркетинг, а мошенничество, и на курсах об этом узнают быстро
- Если ведёшь через свой платёжный сервис: подключение Tilda-приёма платежей — в `05_Формы, заявки, CRM.md`

## Блок 8. Частые вопросы

**Заголовок блока:**
```
Вопросы
```

**Вопрос-ответ 1:**
```
У меня совсем нет опыта. Это нормально?
Да, курс рассчитан на старт с нуля. Модуль 1 начинается с того, как вообще взять микрофон в руку.
```

**Вопрос-ответ 2:**
```
Нужно ли покупать технику?
Нет. Модуль 3 начинается с минимального комплекта и объясняет, что можно оставить на площадке, а что стоит возить своё.
```

**Вопрос-ответ 3:**
```
Сколько времени в неделю?
5–7 часов. Шесть недель. Если времени меньше, курс растягивается — модули не сгорают, доступ навсегда.
```

**Вопрос-ответ 4:**
```
Я веду, но только на дружеских свадьбах. Будет ли польза?
Да, свадьба — самый сложный формат, он в модуле 5. Плюс модуль 6: свадьбы друзей не оплачивают.
```

**Вопрос-ответ 5:**
```
Получится ли заработать?
Заработаете ли вы после курса — зависит от вас. Курс даёт систему, сценарии и понимание профессии: цена, договор, первые заказчики. Гарантировать заработок нельзя, и я не буду.
```

**Пометка:** вопрос 5 — самый важный и самый честный. Прямое «не гарантирую» вызывает больше доверия, чем обещание дохода. Оставь.

## Блок 9. Заявка / покупка

**Заголовок блока:**
```
Записаться
```

**Подзаголовок:**
```
Напишите, как вас зовут и куда прислать доступ.
```

**Поля формы:**

| Поле | Тип | Обязательное |
|---|---|---|
| Имя | Текст | Да |
| Telegram или почта | Текст | Да |
| Опыт ведения | Многострочное поле | Нет |
| Вопросы | Многострочное поле | Нет |

**Кнопка:**
```
Отправить
```

**Мелкий текст:**
```
Нажимая «Отправить», вы соглашаетесь с [Политикой конфиденциальности].
```

**Пометка:** поле «опыт ведения» необязательное, но отвечают на него охотнее остальных — и по ответу сразу видно, что писать человеку в первом сообщении.
