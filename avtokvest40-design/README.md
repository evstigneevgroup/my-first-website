## Логотип и идея

**Словесный знак «АВТОКВЕСТ» + плашка «40»** — основной логотип: бренд пишется словом, регион — фирменной плашкой с кодом **40** (Калужская область).

- **Градиент «Вольт → Циан»** — свет фар ночью и «цифровая» энергия игры.
- **Дескриптор** «АВТОКВЕСТЫ И КВЕСТЫ · КАЛУГА» и фирменный слоган **«Пришёл! Увидел! Вписал код!»** — из реальных афиш сообщества.
- **Знак-пин с «40»** (`logo-mark`, аватар, вертикальная компоновка) — метка на карте: *поиск локаций* (квест) и *свой регион*.

## Шрифты

- **Дисплей — Unbounded** (OFL, бесплатная) — логотип, заголовки, цифры. Локальные файлы в `tools/fonts/` (ExtraBold / Bold / Medium, инстансированы из вариативной).
- **Текст — Golos Text** (OFL, бесплатная). Посты, подписи, интерфейс.

Всё, что запечатано в файлы (логотипы, шапки, носители), **переведено в кривые** — шрифты для открытия/печати не нужны. Для новых материалов используйте те же бесплатные гарнитуры: [Unbounded](https://fonts.google.com/specimen/Unbounded) и [Golos Text](https://fonts.google.com/specimen/Golos+Text).

## Логотип: правила

**Можно:** свободное поле ≥ высоты знака; знак отдельно как аватар; логотип на тёмном фоне или на фото с затемнением.

**Нельзя:** менять цвет и градиент, добавлять обводки/тени, растягивать и наклонять, ставить на пёстрый фон без подложки, менять начертание «40» или переносить его.

## Шаблон шапки ВК

- Основной размер: **1590 × 400 px** (ПК).
- На телефонах ВК показывает **центральные 1196 × 400** — всё важное держим в этой зоне. Готовый файл с разметкой: `vk/cover-1590x400-guide.svg` / `exports/cover-1590x400-guide.png`.
- Аватар (400 × 400) при просмотре перекрывает левый нижний угол шапки — не размещайте там важное.
- Загрузка: *Управление сообществом → Обложка* (PNG). Для «живой обложки» — `cover-living-1080x1920`.

## Пересборка

```bash
cd avtokvest40-design
node tools/build.js       # собрать SVG из исходника
bash tools/render.sh      # отрендерить все PNG в exports/
```

`tools/build.js` собирает всю графику из геометрии и кривых шрифтов — правьте цвета, тексты и размеры там.
