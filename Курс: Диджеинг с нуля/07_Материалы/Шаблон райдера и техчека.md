# Шаблон райдера и техчека

Два списка: что требует организатор и что везёт диджей. Отправляется организатору за 5–7 дней до мероприятия (урок 6.4).

**Зачем два списка.** Райдер — это список требований от организатора к вам. Техчек — список требований от вас к организатору. Один документ, который читают обе стороны и подписывают, снимает почти все технические ссоры: «а у нас розетка одна», «а стол у нас узкий», «а мы думали, вы привезёте колонки».

---

## А. Райдер: что нужно от организатора

```
РАЙДЕР ДИДЖЕЯ
Площадка: _______________
Мероприятие: _______________  Дата: _______________
Исполнитель: _______________  Тел.: _______________

1. ДОСТУП И ВРЕМЯ
   [ ] Доступ на площадку за 2 часа до начала слота
   [ ] Возможность приехать и уехать в любое время слота
   [ ] Место для парковки и разгрузки: _______________
   [ ] Пропуск / список на въезде: _______________

2. ЭЛЕКТРОСНАБЖЕНИЕ
   [ ] Розетка 220 В, свободная, не в одном удлинителе с чайником
   [ ] Отдельная розетка для ноутбука (или разрешение на тройник)
   [ ] Розетки на расстоянии не дальше 2 м от стола — удлинитель в длину 3–5 м
   [ ] Если розетка одна: разрешаем тройник и сетевой фильтр
   [ ] Стабилизатор напряжения на площадке: да / нет

3. СТОЛ И ПРОСТРАНСТВО
   [ ] Стол для оборудования: ширина ____ см, глубина ____ см, высота ____ см
   [ ] Стол не навесной, стоит устойчиво, ножки не разъезжаются
   [ ] Место у танцпола шириной не меньше 1 м
   [ ] Стол не стоит в проходе, входе и на пути к санузлу
   [ ] Стул: да / нет (при 4-часовом слоте он нужен)

4. ЗВУК НА ПЛОЩАДКЕ
   [ ] Звуковая система: ____________________ (модель, мощность, число колонок)
   [ ] Микшерный путь: 2 входа (линейных), 2 выхода для наушников
   [ ] Микрофон: есть / нет, тип разъёма ____________
   [ ] Кабели площадки: ____________
   [ ] Если своей системы нет — подключение с моего оборудования разрешено: да / нет

5. ПИТАНИЕ И БЫТ
   [ ] Еда и вода для диджея: включено / не включено (нужно на 4–5 часов)
   [ ] Туалет: _______________
   [ ] Умывальник: _______________
   [ ] Раздевалка / место для переодевания: _______________
   [ ] Место для хранения вещей на время выступления

6. БЕЗОПАСНОСТЬ ТЕХНИКИ
   [ ] Ответственный за сохранность аппаратуры во время выступления
   [ ] Стол под охраной или в поле зрения ответственного
   [ ] Провода убраны или закрыты — об этом заботится площадка
   [ ] Доступ к технике ограничен: только я и ответственный

7. ПРОГРАММА И ФОРМАТ
   [ ] Ожидаемый жанр: _______________
   [ ] Ограничения по музыке (табу, возраст, «без»): _______________
   [ ] Сцена в программе: объявления в микрофон / фон без объявлений / только музыка
   [ ] Начало слота строго в ____ : ____ или по сигналу ведущего
   [ ] Есть ли пауза в слоте (тост, награждение, фото): _______________ мин
   [ ] Кто отвечает за порядок на танцполе

8. ОПЛАТА
   [ ] Способ: наличные на площадке / перевод до слота / по счёту
   [ ] Когда: до начала слота (не после)
   [ ] Кто передаёт деньги: ____________________, тел. _______________
   [ ] Аванс 50 % получен: «____» ____________ 20____ г., ____ ₽

9. ЗАПАСНЫЕ ВАРИАНТЫ
   [ ] Если диджей заболел за сутки — кого зовём: _______________
   [ ] Есть ли резервный ноутбук на площадке для подстраховки
   [ ] У кого остаётся контакт организатора в ночью

10. КОНТАКТЫ
   Организатор: _________________ тел. _______________
   Ответственный на площадке: _______________ тел. _______________
   Звукорежиссёр площадки (если есть): _______________ тел. _______________
```

## Б. Техчек: что везёт диджей

```
ТЕХНИЧЕСКИЙ ЧЕК ДИДЖЕЯ
Исполнитель: _______________  Дата: _______________
Мероприятие: _______________  Площадка: _______________

1. КОНТРОЛЛЕР И СОФТ
   [ ] Контроллер 4 канала: ____________________ (модель)
   [ ] Программное обеспечение: rekordbox / Serato DJ / Traktor
   [ ] Стили загружены и проверены
   [ ] Требует 220 В, отдельная розетка

2. НОУТБУК
   [ ] Ноутбук с библиотекой и плейлистом
   [ ] 2 USB-порта, один свободен постоянно
   [ ] Заряжен на 100 %, спящий режим отключён
   [ ] Экран не гаснет во время слота

3. НАУШНИКИ
   [ ] Основные: проводные, закрытого типа, ____________ (модель)
   [ ] Запасные: ____________ (модель) или «нет, сознательно»
   [ ] Кабель наушников проверяется на отсутствие излома

4. КАБЕЛИ
   [ ] USB с данными 1–2 м — 2 штуки (основной и запасной)
   [ ] Аудиокабели 6,3 мм — 2 штуки
   [ ] Аудиокабели 3,5 мм — 2 штуки
   [ ] Переходники: 6,3 ↔ 3,5, mini-XLR ↔ XLR
   [ ] Все кабели проверены: излом в штекере — частая поломка

5. ПИТАНИЕ
   [ ] Блок питания контроллера (штатный)
   [ ] Удлинитель 3–5 м с тройником
   [ ] Сетевой фильтр
   [ ] Powerbank с кабелем
   [ ] Фонарик (свет на площадке гаснет)

6. НОСИТЕЛЬ И РЕЗЕРВ
   [ ] Запасная флешка / SSD с копией библиотеки
   [ ] На флешке: плейлист слота + план Б (8 треков)
   [ ] Все треки плана Б проверены воспроизведением
   [ ] На флешке нет треков, которых нет в библиотеке

7. РАБОЧЕЕ МЕСТО У СТОЛА
   [ ] Поверхность стола достаточна для ноутбука и контроллера (нужно 60 × 40 см)
   [ ] Стол устойчив, кабели не на краю
   [ ] Я стою так, что меня видит весь зал, а лягушки не лежат у микрофона
   [ ] Кроссфейдер не перекрыт стеклом, кружкой или локтем

8. ЧТО МНЕ НУЖНО ОТ ПЛОЩАДКИ (повтор, ключевое)
   [ ] Звук работает в зале (система ____________________)
   [ ] Розетка свободна и не в одном удлинителе
   [ ] Слот начинается вовремя
   [ ] Оплата до начала слота
   [ ] Еда и вода на время слота

9. ЧЕГО НЕ ДЕЛАЮ Я
   [ ] Не играю за стеной и не из подсобки: вижу танцпол
   [ ] Не подключаюсь к чужой технике без её проверки
   [ ] Не играю в наушниках с открытыми чашками
   [ ] Не оставляю технику без присмотра

10. ЕСЛИ НА ПЛОЩАДКЕ ПРОБЛЕМА
   [ ] Есть контакт звукорежиссёра площадки
   [ ] Есть доступ к розетке, удлинитель мой
   [ ] Мой план Б (сет на 30 минут) загружен на флешку и открыт
   [ ] При невозможности обеспечить звук работаю без звука по оговорённому плану
```

## Как это выглядит в сообщении

```
Добрый день.

Еду на ваше мероприятие __.__.20__, слот с __ : __ до __ : __.

Список от меня (техчек):
1. Нужна свободная розетка 220 В рядом со столом.
2. Нужен стол шириной от 60 см, устойчивый, с доступом к сети.
3. Нужна возможность приехать за 2 часа и уехать сразу после слота.
4. Подтвердите звуковую систему: ______________ (модель).
5. Еда и вода на слот — если можно, буду благодарен.

Мой комплект: контроллер 4 канала, ноутбук, проводные наушники,
удлинитель 3–5 м с тройником, сетевой фильтр, запасной кабель,
запасная флешка с копией библиотеки.

Программу по минутам пришлю за 5 дней до даты.
Оплата 50 % получена, расчёт 50 % до начала слота.

Подтвердите, пожалуйста, три пункта: розетка, стол, доступ за 2 часа.
```

**Правило отправки:** не отправляйте техчек одним файлом без сопровождения. Файл прочитают позже, сообщение — сейчас. Сопроводительное сообщение занимает 12 строк и экономит один приезд.

## Подтверждение на площадке

Первые 10 минут после подключения. Сверяйте по чек-листу «за час»:

```
[ ] Розетка найдена, доступ есть, удлинитель не нужен или есть
[ ] Стол подходит, розетка в пределах 2 м
[ ] Звук на площадке включён, я слышу его в колонках
[ ] Мой выход в систему работает: в колонках слышно оба деки
[ ] В наушниках слышно оба деки раздельно
[ ] В дальнем углу зала музыка слышна
[ ] В двух метрах от колонки не оглушает
[ ] Программа сета открыта, первый трек на позиции 00:00
[ ] План Б открыт и доступен без ноутбука
[ ] Ответственный за технику представлен и знает, кто я
[ ] Мне сказали, когда начинается слот (время точное)
```

**Одно замечание, которое стоит сделать сразу:** если что-то не совпадает с техчеком — сказать в первые 10 минут. Не в середине вечера. Проблема, о которой вы сообщили до начала, решается за 5 минут; проблема, о которой вы сообщили в 23:40, — за 5 минут плюс испорченный вечер.
