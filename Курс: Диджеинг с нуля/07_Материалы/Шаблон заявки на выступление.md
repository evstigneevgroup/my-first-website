# Шаблон заявки на выступление

Анкета для организатора площадки: что нужно знать до того, как вы согласились играть. Заполняется в момент, когда вам предлагают слот (уроки 6.1, 6.2).

**Зачем анкета.** Обычно площадка предлагает слот одной фразой: «давайте в пятницу». Ответить на это «давайте» без ответов на девять вопросов — риск, что вечер пройдёт не так, а вы будете узнавать об этом на месте. Анкета заполняется вами, а не организатором: отправьте пустую форму и ждите ответов.

---

## Форма заявки

```
ЗАЯВКА НА ВЫСТУПЛЕНИЕ ДИДЖЕЯ

Заполняет: ____________________________ (диджей)
Заполняется: _______________

1. ПЛОЩАДКА
   Название: ______________________________________________________________
   Адрес (точный, с этажом и заходом): ______________________________________
   Район / метро: _______________
   Ссылка на площадку (сайт, карта, соцсети): ____________________
   Тип площадки: клуб / бар / караоке / ресторан / банкетный зал /
                 лофт / открытая площадка / домашняя вечеринка
   Вместимость зала: ____ человек
   Вместимость танцпола: ____ человек
   Есть ли сцена / подиум: нет / есть, размер ____ × ____
   Есть ли парковка: нет / есть, ____ мест
   Работает ли площадка в этот день (другие мероприятия): ____

2. ДАТА И ВРЕМЯ
   Дата мероприятия: _______________
   День недели: _______________
   Начало мероприятия: ____ : ____
   Мой слот: с ____ : ____ до ____ : ____
   Длительность слота: ____ минут
   Окно доступа на площадку: с ____ : ____
   Есть ли репетиция/саундчек: ____ : ____
   Мероприятие повторяется (серия, сезон): _______________

3. ФОРМАТ МЕРОПРИЯТИЯ
   Тип: клубная вечеринка / свадьба / юбилей / корпоратив /
        студенческая тусовка / фестиваль / день рождения /
        Новый год / другое
   Возраст гостей: от ____ до ____
   Ожидаемое количество гостей: ____ человек
   Ожидаемое количество танцующих: ____ человек (ваша оценка)
   Мужчин / женщин примерно: ____ / ____
   Особые гости (приглашённые, возрастные группы, спортсмены,
   блогеры): ____________________
   Формат столов: _______________
   В программе есть: банкет / тамара / конкурсы / шоу-программа /
                     танцевальные номера / речи / награждения
   Моё место в программе: ____ (номер выступления, ориентировочно)

4. ЖЕЛАНИЕ ПО МУЗЫКЕ
   Предпочтительный жанр: ____________________
   Что точно нельзя: ____________________
   Ограничения по вокалу: нет / есть, ____________________
   Ограничения по темпу: нет / есть, от ____ до ____ BPM
   Пожелания по «первому танцу»: ____________________
   Обязательные треки или артисты: ____________________
   Есть ли пожелания гостей (доска пожеланий, голосования): ____
   Играть ли русский язык: да / нет / по ситуации
   Играть ли зарубежное: да / нет / по ситуации
   Отдельно: успеваем ли мы сменить жанр по ходу вечера (да/нет,
   если заказчик ожидает этого)

5. ГРОМКОСТЬ И ЗВУК
   Звуковая система площадки: ____________________
     колонки: ____ шт., мощность ____ Вт
     микшер: ____ входов / ____ выходов
   Есть ли микрофоны: ____ шт., тип ____________
   Жёсткий лимит громкости (децибел, требования арендодателя): ____
   Есть ли ограничение по времени суток: до ____ : ____
   Нужно ли играть тихо в отдельные периоды (речи, тосты):
     да, в _______________ ; нет
   Мониторинг: я привозу наушники, площадка даёт колонки для зала
   Есть ли звукорежиссёр площадки: _______________ тел. _______________

6. ТЕХНИЧЕСКИЕ УСЛОВИЯ
   Стол для оборудования: есть / нет, размер ____ × ____ см
   Розеток свободных: ____
   Расстояние от розетки до места установки: ____ м
   Есть ли возможность приехать за 2 часа: да / нет, с ____ : ____
   Раздевалка: _______________
   Туалет: _______________
   Еда для диджея: включено / не включено
   Безопасность техники: кто отвечает _______________

7. ОПЛАТА
   Гонорар за слот: ____________ ₽
   Способ: наличные / перевод / по счёту
   Когда платят: аванс до даты / в день выступления / после
   Есть ли аванс и какой: ____ % = ____ ₽
   Оплата за проезд: ____________ ₽
   Оплата за ожидание: ____ ₽ / час
   Другие условия: _______________
   Мои условия отмены (сообщить устно, продублировать в договоре):
     за 14+ дней — полный возврат, за 7–13 дней — 50 %,
     менее 7 дней — аванс не возвращается

8. ПРОДВИЖЕНИЕ
   Можно ли снимать видео и фото с выступления: да / нет
   Можно ли использовать запись сета в соцсетях: да / нет / с указанием
   Есть ли у площадки соцсети и можно ли выложить анонс: _______________
   Разрешение на съёмку гостей: ____________________

9. КОНТАКТЫ
   Организатор (ФИО): ____________________
   Телефон: _______________
   Мессенджер: _______________
   Ответственный технически на площадке: ____________________
   Телефон: _______________
   Ссылка на чат сбора заявки (если есть): ____________________
```

## Что отправлять площадке

Не анкету целиком. Анкета — ваш рабочий документ. Площадке отправляется короткое сообщение:

```
Здравствуйте. Готов рассмотреть выступление __.__.20__, слот
с __ : __ до __ : __.

Чтобы взять слот, мне нужно знать:
1. Точное число гостей и примерный возраст.
2. Желаемый жанр и то, что точно нельзя ставить.
3. Звуковая система площадки: модель, сколько колонок.
4. Есть ли лимит громкости и окно тишины (речи, тосты).
5. Розетка и стол для оборудования, доступ за 2 часа.
6. Гонорар и порядок оплаты, есть ли аванс.
7. Кто на площадке отвечает за технику в момент выступления.

Пришлю программу по минутам за 5 дней до даты.
```

## Как отвечать на «а какой у вас опыт»

```
Пока нет большой строчки в резюме, отвечаю по фактам:

— всего сыграно сетов: ____, из них за последний год: ____;
— форматы: ____________;
— техника: 4-канальный контроллер, софт ____________,
  мониторю в проводных наушниках, сведение по сетке и по Camelot;
— подготовка: программа по минутам за 5 дней, план Б на 30 минут,
  копия библиотеки на флешке, запасные наушники и кабель;
— приезжаю за 2 часа, играю весь слот в наушниках, убираю за собой.

Готов начать со слота на 60 минут и вашего рекомендательного
гонорара для площадки такого формата.
```

**Чего не писать:** «я только начинаю, но возьму дёшево» — это приглашение перебить цену. «Я новичок» — честно и уместно один раз, в ответ на прямой вопрос о опыте, после чего идёт список того, что вы умеете и как готовитесь.

## Когда площадка тянет с ответом

| Ситуация | Что делать |
|---|---|
| Молчат 2 дня после заявки | Написать один раз: «Слот ещё актуален? Нужно понимать, брать дату» |
| Спрашивают «а сколько стоит» раньше, чем прислали ТЗ | Назвать вилку по формату и уточнить: «точную цену назову после числа гостей и системы» |
| Требуют процент с продажи бара | Считать на бумаге: 15–20 % с продажи бара при обороте 300 000 ₽ в вечер — это 45 000–60 000 ₽, но без гарантии оборота. Считайте только при фиксированной сумме |
| Просят играть 6 часов за ту же цену | Пересчитать: 60 минут — 8 000–15 000 ₽, значит 6 часов — 48 000–90 000 ₽. Соглашаться на «час по цене получаса» вы работаете бесплатно |
| Не платят ничего, но «опыт» | Согласиться только один раз, не больше двух, и только с записью слота. Бесплатные слоты — это вход в площадку, а не способ заработка |
