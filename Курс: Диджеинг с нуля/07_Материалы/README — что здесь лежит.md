## Правило копирования

**Один выход — одна копия шаблона.** Файл называйте по дате и площадке: `2026-05-16_клуб_Юг_программа.md`. Заполненную программу сета не переиспользуйте под следующий вечер: через три выступления вы перестанете понимать, какой трек на какой минуте стоял. Исходный шаблон с правками в виде лишнего столбца — самая частая причина «я не знаю, что играл в прошлый раз».

```
07_Материалы/            ← шаблоны, не трогаем
Мои_сеты/2026-05/2026-05-16_клуб_Юг_программа.md   ← копия программы
Мои_сеты/2026-05/2026-05-16_клуб_Юг_плейлист.md    ← копия плейлиста
Мои_сеты/2026-05/2026-05-16_клуб_Юг_договор.pdf     ← копия договора
```

Три файла на выступление — программа, плейлист, договор. Этого достаточно, чтобы восстановить любой вечер по памяти через полгода.

## Порядок работы над выступлением

```
За 14–10 дней  Заявка на слот или ответ организатору, отправка КП
За 10–7 дней   Райдер и техчек организатору, договор, аванс 50%
За 7–5 дней    Отбор треков в таблицу учёта, черновик программы сета
За 5–3 дня     Программа сета заполнена полностью, каждый трек проверен
                в наушниках, hot cue расставлены, план Б на 30 минут готов
За 2–1 дня     Чек-лист сетаппа, сборка и проверка, резервная копия на носителе
За день        Чек-лист «за день»: одежда, еда, вода, зарядка, билеты, наушник
За час         Чек-лист «за час»: 10 пунктов, после них — не трогать технику
После выхода   Тетрадь отказа: сразу, пока помните. Плюс строка в таблицу учёта
Через 3 дня    Запрос отзыва у организатора, запись сета в соцсети (урок 6.5)
```
